# 根据实际变化调整计划

本实验沿用现有 Store、CLI 和官方 Codex Harness，不生成新小说。完整三章来自固定前置，经 Store 在新 UUID 库人工初始化；前置进度、核对和旧导出原样保留。教师准备一处第二章结尾的人工改动，观察实际保存后哪些后续条件需要重新判断。

## 独立运行

在解压后的项目目录执行，固定环境为 Node.js 24.12.0 与 pnpm 11.20.0：

```shell
pnpm install --frozen-lockfile --virtual-store-dir .pnpm
pnpm build
node scripts/prepare-replan.mjs --folder my-replan
```

准备命令打印本次作品 ID 和数据库路径。它不会覆盖已有材料目录或数据库；重复实验需另取目录，作品 ID 默认随机生成。全部初始化回执、真实 CLI 读回、改前全文、完整人工保存输入和本次完整任务输入在 `my-replan`。旧导出复制自固定原件，初始化后须与 Store 当前完整文本严格相同；失败时停止，不用换行转换冒充字节相同。

先完整阅读改前和拟改后的第二章，确认本轮要观察的人工变化，再通过已有入口保存。以下的数据库路径和作品 ID 使用准备命令打印的实际值：

```shell
node dist/cli.js save my-replan/第二章-人工修改完整输入.json --db 本次数据库路径 --work 本次作品ID
node dist/cli.js chapter 2 --db 本次数据库路径 --work 本次作品ID
node scripts/capture-stage.mjs --folder my-replan --output runs/人工改稿后.json
```

输入的修订来自准备时的实际读回；若其他入口已改变稿件，不能只替换修订号，应先重读和对照完整正文。本实验按顺序运行，保存仍是草稿，不采用或发布；第一、三章保持原文。`basisCurrent` 只能定位保存时引用是否变化，不能断言第三章的语义是否相容。

## 真实 AI 任务

无需模型也可以对照完整材料推演计划。要执行本节的真实调用，需本机 Codex 的可用账户与模型配置；官方 SDK 使用现有配置，不在项目写入凭据。完整任务输入已由准备命令按本轮实际 ID 生成，先阅读再运行：

```shell
node scripts/replan-session.mjs --folder my-replan
```

这是一轮官方新会话，只读取本轮资料并保存 `调整后的计划.md` 与 `当前进度.md`。它不执行计划中的小说修改、保存、采用、导出或人的阅读。SDK 公共输入、全部事件、最终文字和运行回执在 `runs/replanning-运行标识`；失败和未完成同样保留。会话结束不等于三章目标已通过，须核对实际文件与当前全文。

旧导出、前置进度、教师变化和当前对象分别保留。旧文件含前置 UUID 的地方是历史原件，不是本次调用凭据或当前修订。人物的午后约定只是课堂构造输入；是否补过渡、保留何种节奏以及采用哪一修订，仍由人决定。本文档不要求网页、多人协作或另建模型循环。
