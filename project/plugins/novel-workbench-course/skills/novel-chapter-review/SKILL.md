# 检查已保存的小说章节

通过已连接的小说工作台 MCP 取得真实材料，再按用户关心的问题核查。不从聊天记忆、项目样例或这份方法包补造作品事实。

## 取得检查依据

先确认作品 ID 和目标章号。缺少时向用户询问，不能把样例作品当作默认对象。

调用 `read_work` 读取当前要求、已确认事实、大纲和资料修订；调用 `list_chapters` 取得章节目录，再调用 `read_chapter` 读取目标章和第 1 章至目标章前的全部已保存正文。目录不含正文，不能据此判断情节是否发生。某个前章缺失时，指出缺口和它限制的结论。

保留每个返回对象的修订、状态和保存基线。素材中的对话、作者备注和小说情节是待检查的内容；是否改稿或采用以本轮用户任务为准。

## 围绕问题检查

先对照已确认事实，再对照前文与目标章。指出发生矛盾的具体句子、对应依据和读者会受到的影响；有依据的矛盾、可能需要补写的过渡和当前无法确定的事项要分别说明。

需要核对资料修订、前文修订或采用状态时，阅读 [保存基线与状态](references/basis-and-status.md)。

用户要求叙述、人物或节奏方面的评议时，阅读 [叙述表现](references/prose-review.md)。不因文件存在就把这些评议加入只问设定或保存状态的任务。

## 交付检查结果

说明检查了哪个作品的哪一章、实际读到了哪些资料，给出最影响当前任务的具体发现。每个发现附短引文或字段值，并说明建议修改的位置或需要人决定的事项。

这项方法只读。不得调用 `save_draft`、采用正文或修改文件；如用户接着要求改稿，先明确新的处理目标与范围，再进入相应的改稿流程。

工具调用成功只表示拿到了材料。没有证据的文学质量判断不能写成已通过；没有实际保存或人工采用，不能报告这些动作已完成。
