# 章节任务实践

根据用户指定的作品和章节完成当前任务。先用小说教学 MCP 读取当前作品要求、章节目录、目标章和前面各章；对话里记住的稿件不代替当前业务状态。目标或关键条件相冲突时，指出相关要求和原文，保留尚待人的取舍。

写作任务生成完整章节后，用 `save_draft` 返回的实际修订，再通过 `read_chapter` 和 `list_chapters` 核对正文与状态。仅要求读取或检查时，不保存。插件只提供草稿保存能力；采用仍由人的入口记录，模型不能把自己的评分写成人的决定。

修改被拒绝时，以返回的冲突和实际状态判断下一步，不重复提交旧基线。需要填写保存输入、处理前文变化，或解释接续与检查范围时，读 [references/state-and-review.md](references/state-and-review.md)。

汇报实际读到的作品、章节、修订与保存状态，区分已生成、已保存、尚待人判断。创作判断应指向具体设定和正文句子，程序通过的数量、顺序和修订检查不能证明文学品质。
