# 固定版本的配置依据

配置针对 `runtime.json` 标明的 n8n 2.41.6 镜像与节点版本。下列文件位于该镜像的 `/usr/local/lib/node_modules/n8n` 程序目录；它们提供配置格式与行为依据，不是本次实际业务执行记录。

| 对象 | 固定程序文件 | 采用范围 |
| --- | --- | --- |
| Data Table | `node_modules/n8n-nodes-base/dist/nodes/DataTable/DataTable.node.js`；`actions/row/insert.operation.js`、`get.operation.js`、`update.operation.js`、`common/selectMany.js`、`common/addRow.js` | 1.1 版本；读取匹配行；显式列映射；插入返回真实完整行；按系统 id 更新 |
| 数据表与行 ID | `node_modules/@n8n/api-types/dist/schemas/data-table.schema.js`；`dist/modules/data-table/data-table-proxy.service.js`；n8n-workflow 的 `DATA_TABLE_SYSTEM_COLUMN_TYPE_MAP` | 列的四种类型；表 ID 为实际字符串；行 id 为系统 number；节点更新返回实际行 |
| 空查询继续 | `node_modules/n8n-core/dist/execution-engine/workflow-execute.js` 的 `ensureAlwaysOutputData` | 没有结果且启用该节点设置时，产生一项空 json，便于下一 If 分支判断 |
| Webhook | `node_modules/n8n-nodes-base/dist/nodes/Webhook/Webhook.node.js`、`description.js` | POST、完整 body、responseMode=responseNode、2.1 版本 |
| Respond to Webhook | `node_modules/n8n-nodes-base/dist/nodes/RespondToWebhook/RespondToWebhook.node.js` | 1.5 版本；JSON 响应与 HTTP 状态；默认后续输出保留输入项 |
| Wait | `node_modules/n8n-nodes-base/dist/nodes/Wait/Wait.node.js` | 1.1、相对五秒；小于 65 秒保持活动，不据此声称持久休眠恢复 |
| If、失败终止 | `node_modules/n8n-nodes-base/dist/nodes/If/V2/IfV2.node.js`、`If.node.js`、`StopAndError/StopAndError.node.js` | If 2.3 的严格类型；true/false 分支位置；Stop And Error 1 实际抛出节点错误 |
| 创建和测试监听 | `node_modules/@n8n/api-types/dist/dto/workflows/create-workflow.dto.js`、`base-workflow.dto.js`、`manual-run.dto.js`；`dist/workflows/workflow-execution.service.js`；`dist/webhooks/test-webhooks.js` | 当前导入字段；triggerToStartFrom.name；测试等待注册；未提供 pushRef 时不发送该项测试推送 |
| 数据表接口 | `node_modules/@n8n/api-types/dist/dto/data-table/create-data-table.dto.js`、`create-data-table-column.dto.js`、`list-data-table-content-query.dto.js`；`dist/modules/data-table/data-table.controller.js` | 两表定义 DTO；实际项目级创建、列读取和行读取契约 |
| 发布 | `node_modules/@n8n/api-types/dist/dto/workflows/activate-workflow.dto.js`；`dist/workflows/workflows.controller.js` | 发布请求需要当前真实 versionId；保存、发布调用和实际发布终态分别核查 |
