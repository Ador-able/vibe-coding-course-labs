## 人的意见如何进入正文

课堂人工输入只把守塔人一句“机芯的事，你看。”替换为“你先看，别动机芯；真要拆，等你师父来了再说。”。标题和其他文字原样。它把查看与拆修的权限分开，是教学新约束，不是用户文学认可，也不是断言 r1 技术错误。

实际编辑器先遇到受控离线失败，完整本地文字保留，业务库未变；重连并读回当前 r1 对照后成功保存完整 r2。等待期间字段不可编辑，实际键盘输入未进入正文；保存后的 HTTP、CLI 与完整一致备份相符。模型尚未再次读取 r2，后续任务必须从当前已保存稿取得这条约束。

## 直接打开完整产物

公开实验包中的 project 为固定 Git 对象原字节源码；完整历史在配套 bundle 中。本轮实际 runs 另行保留，数据库状态采用 node:sqlite 官方 backup 取得一致快照。源库在运行时采用 WAL，不要只复制主 sqlite 文件来推断当前完整内容。

可在自己的恢复目录中复制选择的快照到新的路径，再打开人工查看入口。不要覆盖正在使用的工作库。

```powershell
Copy-Item -LiteralPath ../数据库快照/模型保存r1.sqlite -Destination data/讨论r1.sqlite
pnpm prototype --db data/讨论r1.sqlite --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea --port 4337
```

r2 的快照为 ../数据库快照/人工改稿r2.sqlite，起点为 ../数据库快照/零章起点.sqlite。上述命令在新的恢复目录执行，data/讨论r1.sqlite 尚不存在。页面仍具备人工保存能力；先阅读判断，不自动采用或发布。

## 三个界面方向

原版、台面与笔记页使用相同业务、完整稿、字段与必要操作。三个方向各自在同一 r1 快照的独立副本完成相同人工流程；实际保存自然时间不同，正式库没有因此追加修订。等待、失败、对照与保存分别验证，整页密度和口吻另行判断。原版保留，学习者可以比较并选择。

## 适用范围

本章 TypeScript SDK/CLI 固定为 0.160.0，实际会话为 gpt-6.1-sol/openai。当前其他 SDK 或 app-server 的事件字段不能直接替代本次类型。自动经验记忆未参与，业务 tasks 表没有新建运行登记。Ctrl+C 的 AbortSignal 实现已核对，但本轮没有实际取消；取消也不能撤回先前业务保存。当前产物均为草稿，不包含人的采用、发布或持续运行保证。
