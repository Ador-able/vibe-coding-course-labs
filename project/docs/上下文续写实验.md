# 为连续任务取得当前材料

这项练习使用同一小说工作台、业务 Store、MCP 服务与成熟 Codex SDK。第一章的人工正文仍是待审草稿；参考摘要和临时构想不能替代工作台当前正文。

## 资料与入口

`inputs/作品资料-r2.json` 是人的完整资料输入，明确第二章目标。从第一章原资料r1恢复后，可通过现有CLI保存这项人工决定。若使用已更新为资料r2的课堂起点，先读取即可，不重复执行更新。更新时使用实际当前资料修订：

```powershell
pnpm lab update inputs/作品资料-r2.json --expected-revision 1 --db data/context.sqlite --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea
```

资料更新成功后，请通过 `show` 与 `work-version` 回查。第一章正文、历史和状态不因新增大纲自动改变；资料版本不同只表示需要判断关系，不证明正文错误。

本轮的完整请求保存在 `inputs/完整任务.txt`。`materials/来稿` 中的摘要和构想都是明确标记的课堂输入，有来源编号和确认状态。Agent 使用已有文件检索与读取能力取得这些材料，并通过 `read_work`、`list_chapters`、`read_chapter` 读取业务当前资料和完整前文。目录不包含正文。

保存第二章时，要求版本、目标正文版本和第一章当前版本来自本次真实返回；成功后仍需完整读回。`save_draft`只能保存草稿，没有人工采用权限。

## 人工查看

```powershell
pnpm prototype --db data/context.sqlite --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea --port 4347
```

页面地址 `http://127.0.0.1:4347/?work=harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea&chapter=2` 可查看第二章的实际保存状态。没有正文时保持空白且不可编辑；第一章可以从章节入口查看。原版、台面和笔记页共享业务、数据、字段和操作，保留给使用者选择。

## 运行范围

运行规则以实际宿主和配置为准。配套任务关闭仓库项目规则的自动注入及配置中的记忆能力；全局用户规则来源仍可能存在。只记录来源路径，不读取或公开受保护正文，不把能力目录的隔离标签解释为全部背景均已排除。

模型任务使用现成SDK观察器和本地批准的业务工具，工作目录只读；不通过直接修改数据库或新文件绕过保存。完整事件、读取返回和持久正文用来核对结果；模型结束通知或自述不能代替保存与人工阅读。
