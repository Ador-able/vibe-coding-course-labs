# 长文分段的采用范围

本轮逐项全文阅读定位记录见《本轮原课原字节与全文定位.json》，15 份原课抽取全文、新闻摘要 PDF 17 页、DeepSearch 两份附加任务全文，以及两张实际 Token 截图已读。原字节与 BOM/LF/CRLF 归一后的摘要分别记录，没有修改原件。网站 plan 源 279/280/281/285 为编纂索引，本节事实沿下列完整原课回查。

## 本地原课

- prompt-099：分块各自整理、汇总与逐块 refine 的材料依赖。原 load_summarize_chain 示例属于旧版本，不作为当前可运行接口复制。
- prompt-125：教材长文实践保留 PDF 元数据、处理范围与分段；课程中的选择十页与整本四百页不是同一次覆盖。历史半分钟/半小时不写为现今性能。
- prompt-132：文章摘要后再压缩成博客/推文，体现用途改变及二次摘要的省略风险；串行演示不能自动写成实际并行。
- prompt-124 与 News-Article-Summarization.pdf：关键点、数量、结构、引用与事实核查分别判断。PDF 中增加样例后的六点、未提供实际 ROUGE 原值的解释和无可定位原文的编号引用不写成质量已证实。本节只采用检查职责，不复制新闻原稿。
- prompt-135：统一分类口径是下一节问题，本节不重做访谈标签矩阵，也不把 65×49 表直接写成 65 个完整分类通过。
- learn-106/107/112/114：字数、条数是实际产物条件；重点保留要求每位作者五条而示例给四条的失败。讲者对内容的赞许不能替代数量核查。
- learn-110：询问来源不证明模型真实查过来源；本节使用原段查支持，不采用投资判断。
- learn-197：视频字幕通过文本/附件整理的用途，文件上传本身不保证全覆盖或绕过模型容量；历史两分钟标题不作本节性能指标。
- deepsearch-096/097/207/208 及 extra-079/080：搜索/抓取/逐页摘要与后续选择的完整链；提示要求 Flash Lite，解答改 Flash，分开归属。最初选择下一动作的输入为274；加入摘要并经过后续轮次后，最后截图中的下一动作输入为9976，前者输出102、后者输出149。这是不同阶段的读数，不是压缩前后对照或全流程总消耗，更不是274K被压成10K。摘要质量和更多评估当时仍留后续，不能据局部用量认定无遗漏。本节不重建搜索代理。
