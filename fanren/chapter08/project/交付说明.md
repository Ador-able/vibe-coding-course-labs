# 第八章实验材料

《青岚修仙录》的四份基础材料与第七章逐字节一致；三种练习都另建数据库，人工导入为资料 r1、三章 r1/draft，不继承生成或采用历史。

## 使用

安装与操作见 README.md。包内带 dist，直接运行即可。原型、跨会话、重规划共用依赖和 materials；只有跨会话 A、B 和重规划会调用模型。重规划可默认使用包内真实 B 实录，不要求先完成 A/B。

## 实际来源

三模型任务均在源码 2715a3c95ebe5f31e508b9f2b8d44f766bd3fdca 上各执行一次。A run 2c4f94e1-fa79-4844-84b7-d01a25e1cf72 在真实导出并逐字节核对后取消；B run 5ad9d334-4e36-4906-9c5c-abc7969914aa 完成且复用既有导出；重规划 run 6c258f93-9e64-4ae1-a4fb-2a4c3c8444aa 完成，仅保存计划与进度。没有重复生成小说或自动采用。任务材料准备时的 b3df017 版本记录与执行时的 2715a3c 分别保留。

materials/跨会话实录 保留真实输入、导出、完整核对、进度、模型报告和原任务清单，根 task.json 只调整归档路径供准备入口读取，原始 task-state/task.json 不变。该目录 README.md 是模型当时读到的原文，不是本包操作入口。materials/重规划实录 是第三任务真实输入与结果；后续改稿、交付、人的阅读均未执行。历史任务内的原路径、时间、版本号仍是历史事实，不是新实验参数。文件对应关系与字节摘要在来源 JSON。

原型实录对应 2715a3c 的实际浏览器运行 555bdd98-a124-4862-8b0a-3dfeeab8684d。三界面独立库均完成保存、等待禁用、旧稿拒绝后保留本地、读取对照、断网未确认及恢复检查；CLI/MCP 完整读回一致。截图不是自动生成的界面示意。

## 失败与限制

开发中首次安装因缺少局部工作区声明进入上级工作区，未改上级清单与锁文件；增加本包 pnpm-workspace.yaml 后独立冻结安装成功。首次宿主预检发现 codex_apps 工具仍可见，隔离配置后预检通过。首次浏览器检查端口 10080 被浏览器拒绝；一次检查因调整布局主动中断，之后固定端口 4339 的完整运行通过。这些失败没有触发任何额外模型任务。模型检索 AGENTS 无匹配的退出码 1 也保留在原事件中，不冒充会话失败。

模型判断用于教学，不能替代人的连续阅读与文学选择。A 的中断由执行器在核对导出后发起，不是随机崩溃。断网检查覆盖本实验实际模拟条件，不证明所有网络失败都未保存。源码宿主使用当前 Codex 账户与模型选择，运行成本依实际模型与完整输入长度变化；没有自动重试。

归档之后只调整独立前置材料读取及操作说明，未重跑三次模型；最终源码版本见 source-version.json。包中不含 .git、node_modules、数据库、账户凭据、私有宿主目录及原始 SDK 事件。
