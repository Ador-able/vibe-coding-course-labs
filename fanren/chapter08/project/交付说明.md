# 第八章实验材料

《凡人修仙传》的作品资料与完整 C03/C04/C05 原文片段供本章练习复用。原型在独立库人工导入为资料 r1、三章 r1/draft，不继承生成或采用历史。

## 使用

安装与构建沿用仓库统一入口，操作见 README.md。原型、跨会话、重规划共用依赖和 materials；只有跨会话 A、B 和重规划会调用模型。重规划可默认使用包内真实 B 实录，不要求先完成 A/B。

## 实际来源

凡人原文跨会话在源码75e35f3bc32d52f468bd21394bddb7f199b9ccc3上各执行一次A/B：A真实导出21798字节后核对一致并取消；B新会话逐字节核对并复用原导出，保存核对与进度，业务五表不变。公开输入、命令返回、文件与独立SQLite快照见课堂记录/凡人原文-20261015/03-跨会话。B中一次比较脚本语法错误及后续修正保留；取消会话用量未取得，B实际用量见报告。

以下跨会话和重规划是青岚材料的历史记录，未冒称凡人原文任务。三次历史模型任务在源码2715a3c95ebe5f31e508b9f2b8d44f766bd3fdca上各执行一次。A run 2c4f94e1-fa79-4844-84b7-d01a25e1cf72 在真实导出并逐字节核对后取消；B run 5ad9d334-4e36-4906-9c5c-abc7969914aa 完成且复用既有导出；重规划 run 6c258f93-9e64-4ae1-a4fb-2a4c3c8444aa 完成，仅保存计划与进度。没有重复生成小说或自动采用。任务材料准备时的 b3df017 版本记录与执行时的 2715a3c 分别保留。

materials/跨会话实录 保留真实输入、导出、完整核对、进度、模型报告和原任务清单，根 task.json 只调整归档路径供准备入口读取，原始 task-state/task.json 不变。该目录 README.md 是模型当时读到的原文，不是本包操作入口。materials/重规划实录 是第三任务真实输入与结果；后续改稿、交付、人的阅读均未执行。历史任务内的原路径、时间、版本号仍是历史事实，不是新实验参数。文件对应关系与字节摘要在来源 JSON。

原型实录在源码 254d07c9634e67030595d385bc224e180a5d0419 上使用凡人原文完成，见课堂记录/凡人原文-20261015/02-原型。三份正式案例各新增一次人工修订，未调用模型。页面、所捕获API、CLI、官方MCP和独立SQLite完整正文一致；旧窗口返回409且两份正文分别保留，受控等待与断网后的输入保护均已核对。图片由页面或实录页原生PDF直接渲染为2560像素宽，二者分别标明，不称屏幕截图。视口、按钮事件方式、网络事件缓冲截断与校准记录范围见目录说明。

## 失败与限制

开发中首次安装因缺少局部工作区声明进入上级工作区，未改上级清单与锁文件；增加本包 pnpm-workspace.yaml 后独立冻结安装成功。首次宿主预检发现 codex_apps 工具仍可见，隔离配置后预检通过。首次浏览器检查端口 10080 被浏览器拒绝；一次检查因调整布局主动中断，之后固定端口 4339 的完整运行通过。这些失败没有触发任何额外模型任务。模型检索 AGENTS 无匹配的退出码 1 也保留在原事件中，不冒充会话失败。

模型判断用于教学，不能替代人的连续阅读与文学选择。A 的中断由执行器在核对导出后发起，不是随机崩溃。断网检查覆盖本实验实际模拟条件，不证明所有网络失败都未保存。源码宿主使用当前 Codex 账户与模型选择，运行成本依实际模型与完整输入长度变化；没有自动重试。

归档之后只调整独立前置材料读取及操作说明，未重跑三次模型；最终源码版本见 source-version.json。Git仓库不收录 node_modules、数据库、账户凭据、私有宿主目录及原始 SDK 事件。
