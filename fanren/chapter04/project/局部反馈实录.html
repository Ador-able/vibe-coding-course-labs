# 选拔开端

王护法在清客院门前催人时，韩立刚把鞋穿好。他摸了摸瘪瘪的肚子，跟着孩子们走出去。本以为还能吃顿早饭，王护法却领着众人一路下山，直到一片竹林前才停住。

晨风吹得竹叶沙沙响。韩立缩了缩脖子，望见昨日的红脸老者站在坡下，旁边还有几个青年。他赶紧站直，唯恐自己落在人群外。

“大家听好。”岳堂主抬手指向竹林，“沿林中小路往前，先过竹林，再攀岩壁，最后登山崖。想当正式弟子，就得在正午前到崖顶。稍晚些，若表现出色，也可能收作记名弟子。”

韩立仰起头，竹梢遮住了山上的去路。他听不懂记名弟子究竟是什么，只把“正午前”牢牢记住。日头如今才升起来，可竹林后还有岩壁，还有一座山崖。

旁边一个孩子踮脚往上望，轻轻吸了口气。韩立也攥紧衣角。他刚满十岁，从未学过拳脚，平日在山里捡柴，只知道哪里能落脚，哪里不能踩。

离家前，三叔坐在他家的土屋里，说自己在七玄门所属的春香酒楼做掌柜，如今能举荐他来应试。父亲原先只抽烟，听说入门后能学武、吃穿有着落，每月还有银钱，才抬头答应。

韩立记得父亲那时的神情。说起大哥当铁匠学徒，每月能拿三十个铜板，父亲也会这样舒展眉头。家里一年吃不上几顿肉，他早想学门本事，挣了钱带回去。

可三叔只能送他来试，眼前这条路，得由他自己走。

岳堂主看了看太阳：“时候到了，出发吧。师兄们在后面保护，不会让你们出危险。”

韩立回头望向那些青年。他们衣衫齐整，站得笔直。他正想着自己若能入门，是否也能穿上这样的衣服，身旁忽然一阵脚步乱响，孩子们已经冲进竹林。他连忙追了上去。

舞岩的锦衣在前面一闪，很快被竹子遮住。先前车上围着舞岩说笑的孩子，也各自找路往上走。韩立沿着小路抬脚，起初还觉得这坡不难，比背着柴回家轻省些。

身后始终有脚步声。他扭头，看见一个瘦长的师兄跟着自己，脸上没有笑意。韩立把到了嘴边的话咽下去，低下身子，继续爬坡。

小路渐渐难走。竹叶盖住浮土，一脚踏上去，鞋底便往下滑。韩立抓住旁边的竹竿，等脚踩稳了才松手。再走几步，他又得伸手去抓，掌心被竹节硌得发疼。

汗沿着额角流下来，衣服贴住后背。他张嘴喘气，腿却越抬越沉。方才还能一步跨过的树根，这会儿要先把脚放上去，再使劲撑起身子。肚里空得难受，胸口也一阵阵发紧。

他终于在一个土堆上坐下，两只手撑着膝盖。呼吸还没平，便回头去看。瘦长师兄站在下方的坡上，衣角垂着，竟连气也不喘。

韩立赶紧转回脸。前方传来断断续续的喘息，看来走得快的人也累了。他想再歇一会儿，可仰头寻找日头时，只看见竹叶缝里的亮光，比进林时高了一些。

已经走了多久？他不知道。竹林还没穿过，后面两段路更没碰到。想到岳堂主说的正午，他把手按在土堆上，慢慢站起来。腿肚子酸得发颤，他扶住竹竿，等那阵酸劲稍退，便往上挪了一步。

林子深处仍有人喘气。韩立擦去快流进眼里的汗，挑一处露出的硬土踩稳，再伸手抓向前面的竹子。
