# 第四章写作实验

根据《凡人修仙传》的现有情节、大纲和设定，练习交付一章可检查的改写草稿。“材料/任务-S1.txt”包含本轮用途、范围、原文、大纲和设定，可以直接交给已有 AI 对话工具，不需要启动额外界面。

## 三种输入

- 无样例：只使用“任务-S1.txt”。
- 冲突样例：追加“样例-冲突.txt”。
- 相容样例：追加“样例-相容.txt”。

两份样例均基于 C03 岳堂主宣布规则的段落，冲突样例只将“正午”替换为“日落”。这是输入条件的受控改动，不能当作原著事实或模型已经犯错的证据。输出仍需逐份核对，不预设样例必然造成错误。

S2、S3 是岩壁攀爬和随墨大夫入谷的后续核对任务，各自包含对应原文。后续复查时先固定方法，再看新结果，不用已看过的结果冒充未见样本。原文依据与输入哈希见“材料/来源核对.json”。

## 实际运行

沿用仓库共用安装与已有 Codex 登录，在本目录运行：

```powershell
pnpm experiment
```

默认依次运行无样例、冲突、相容、相容、冲突、无样例六个新会话。只做单次观察可加 `--condition none`、`conflict` 或 `consistent`；只保存输入、不调用模型可加 `--prepare`。

每次运行独立保存到“运行记录”，包括固定输入、源码版本、完整提示、公开事件、输出、耗时、用量和错误。每次最多等待180秒，失败保留，不自动重试。沿用默认模型，关闭旧记忆使用和新记忆生成，不读取其他故事材料。

按“材料/核对记录模板.md”读完整草稿，分别判断事实、完整交付与文学品质。生效型号、实际账单、人工审阅工时未取得时保留未知；单轮结果不作普遍结论。
