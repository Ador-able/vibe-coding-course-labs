# 四章终审的交付范围

本轮候选为 qinglan《青岚修仙录》的当前四章待审稿。范围在终审前确定：林青为了当前炼气阶段的困难争取进入藏书阁，找到并实际借到可读法门，完成与执事的交接，带书回住处阅读、对照旧记录并进行一次有限尝试。

需要判断这段行动是否形成可读的阶段成果，四章之间的人物、物品、动作与限制是否接得上，以及最后的未知异常是否适合这份交付。不能将“借到书”自动等同于“练习已经奏效”，也不以第四章必须筑基、解决散息或解释铜片、东架及木闩异常为验收条件。允许未解异常，不等于可以忽略前文建立的动作条件或阶段收束。

当前四章均为草稿。第四章经历一次真实模型保存后停止，以及编者的一处实际改稿：回屋先关门插闩，再整理桌面。编者还暂不执行“杂役打断阅读”的建议，以保留读书、辨察和有限尝试的推进。前三章的暂用不是采用；当前终审仍需完整阅读，不凭此前判断直接通过。

这一次只让模型取得当前完整资料和四章正文，给出有原句依据的终审意见。是否保留、局部修改、采用或暂不交付，由编者读过实际意见与当前全文以后决定；不得预先写死改句、采用修订或导出结果。第一、二章此前的可能省略亦留待本轮全文判断，不把疑点预先变成已确认错误。

权限限于只读终审，工作台正文、资料和历史保持。任务入口记录运行状态与任务条目；模型不负责修改旧任务状态、保存小说、采用或写出交付文件。实际文件导出留到人的判断之后，通过已有业务入口完成。
