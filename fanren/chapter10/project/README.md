# 凡人修仙传：连续 Agent 练习

沿用课程仓库的依赖与已有 Codex 登录，复用小说工作台、MCP、Skill 和官方 SDK。材料是用户提供的《凡人修仙传》完整原文片段 C03、C04、C05，以及从这三段整理的大纲与设定。教学章号不是原书章号，片段大纲也不是全书大纲。

## 首篇：原文导入为待审稿

从本目录建立独立的零章练习库并核对插件。初始化与宿主检查不调用模型：

```powershell
pnpm practice:new
pnpm host:check
```

随后执行一次明确的导入任务；这一步会调用模型，最长十分钟，不自动重跑：

```powershell
pnpm agent --prompt inputs/158-凡人原文导入.txt --chapter 1
```

Agent 应取得当前完整大纲、设定和原文，通过工具保存教学第 1 章，再读回正文与目录。原文来源、分隔规则和摘要在 `materials/凡人原文/原文来源.json`，业务初始化资料在 `seed/凡人修仙传.json`。这次只导入 C03，不续写、不纠正原文，不把后续 C04/C05 的事件并入。

模型运行输入、公开事件、前后业务记录和报告保存在本轮 `runs/编号/`。`origin: agent` 标记保存入口，文字仍来自忘语原作；运行结束、正文保存和人的采用分别核对。遇到失败，保留实际返回，先读当前状态，不直接重复覆盖。

## 人工查看与核对

```powershell
pnpm prototype
pnpm lab chapter 1
```

打开终端给出的工作台地址，选择教学第 1 章，核对完整章名、正文、修订和草稿状态。页面、CLI 与 MCP 使用同一个 Store；页面保存属于人的新修订，不会改动来源文件。

人工校订先确定具体原句和范围，再保存，保留旧版本。若连接中断或基线变化，保留本地编辑，读取当前稿比较后决定；保存不会自动采用或发布。

## 运行与恢复范围

`practice.json` 只记录当前练习库。每次 `practice:new` 建立新库，不覆盖旧库；已有页面服务仍连接启动时的库，切换练习后应先停止自己的旧服务，再重新启动。代码变化后才需要重新构建。

`practice:restore --snapshot 路径` 可以恢复公开实录中的完整业务快照，不会重新调用模型，也不会恢复私有 Harness 会话。登录、插件缓存和会话保存在忽略的 `runs/private-codex-home`；本章关闭个人记忆的读取与生成，不改全局配置。源码版本记录实际 Git 提交。

`materials/` 中的旧青岚资料及其记录保留原有来源身份，不属于本轮凡人实测；不能用旧正文或旧运行数字代替本轮产物。
