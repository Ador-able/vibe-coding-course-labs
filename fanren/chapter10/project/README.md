# 青岚修仙录：连续 Agent 练习

本章沿《门内一声》的铜片手影分支继续，并用独立教师作品《雨过讲堂》练习终审。两部作品分别保存；第八、九章的翻页和四折纸情节没有并入本章。

只读实验实录时，直接打开 `materials/` 中的完整正文、输入、工具事件与最终回答，不需要安装或调用模型。需要进入工作台时，按下面的命令恢复本节起点。

## 恢复本节起点

沿用仓库根的统一安装和构建，以及已有 Codex 登录，在本目录恢复起点并核对宿主：

```powershell
pnpm practice:restore
pnpm host:check
```

默认恢复第一章真实模型任务完成后的完整记录。每次恢复会建立新练习库，不覆盖旧库；当前库保存在 `practice.json`。宿主检查只绑定本章私有插件、核对实际工具与 Skill，不调用模型。登录凭据和会话留在 `runs/private-codex-home`，不属于公开材料。

源码改动后才需要重新构建。交付材料中的 `source-version.json` 用于记录源码版本，运行不要求 Git 仓库。

## 查看与人工编辑

```powershell
pnpm prototype
```

打开终端给出的地址，选择章节、编辑并保存。遇到冲突或连接中断，先保留本地修改，再读取当前稿对照。保存仍是草稿，只有明确的人工采用命令才会改变采用状态。

切换练习起点后，先停止旧页面服务，再重新运行 `pnpm prototype`。已启动的服务仍连接启动时的库；人工命令和新 Agent 任务则读取当前 `practice.json`。

查看当前资料与正文：

```powershell
pnpm lab show
pnpm lab chapter 1
```

## 从第二章起点继续

第一节已有真实起草和人工改句记录。需要独立开始第二节时，可以直接恢复完整起点，不必重新生成第一章：

```powershell
pnpm practice:restore --snapshot materials/起点/161-任务前.json
pnpm host:check
```

读完 `inputs/161-完整任务.txt` 与 `materials/来稿/` 后，执行一次第二章任务：

```powershell
pnpm agent --prompt inputs/161-完整任务.txt --chapter 2
```

这条命令会调用模型。它通过官方 SDK 开始或接续会话，用插件工具读取和保存；任务开始前自动核对当前库与插件绑定。最长十分钟，不自动重跑。完整输入、公开事件、前后业务记录及结果报告保存在本轮 `runs/编号/`。

失败、取消与成功结束分别记录，保存过的正文不会因取消自动撤回；应从工作台或人工命令重新读取实际对象。运行完成、保存成功和人的认可分别判断。

## 本章共用的能力

`export_work` 已在此起点中提供，工具组合课练习它与读取、方法的配合。局部修订仍使用已有的 `revise_excerpt`：对象、修订与选区由人绑定，工具保留选区外原文，旧基线必须拒绝。会话接续使用 Harness 的原生接口，不另外实现模型调度循环。

第一章历史记录没有业务 Task 行；本章新的任务会单独记录 Task 与 Harness 会话标识。恢复旧记录不等于新执行过模型。历史绝对路径仅标识当时环境，实际操作以本次返回为准。

## 结果与证据

`materials/189-A-课堂采用交付/青岚修仙录-四章课堂采用.md` 是编者读稿、局部消歧和逐章采用后，由已有业务入口导出的四章全文。采用会增加章节修订，保留原保存基线；因此采用状态与 `basisCurrent` 提示可能同时存在，不能把提示当作采用失败，也不应为更新数字而重存正文。

独立短篇的课堂采用全文为 `materials/189-B-课堂采用交付/雨过讲堂-三章课堂采用.md`。它以教师三章为起点，经过一次只读终审、编者在第二章补清背箱动作、逐章采用和实际导出；没有把教师稿称为本轮模型生成。

实录保留自然出现的失败与限制：第二章人工保存曾因资料基线变化被拒绝，183-A 在真实保存后被教学入口停止；178 模型重算了文本长度、字节数与摘要，汉字数来自提供的程序报告，不能概括成它重算了全部统计。189-B 最终回答自述进行了汉字计数和导出重组，但原命令只证实来源、对象及四表比较；编者另行核算的结果单独保存在 `materials/189-B-三章终审实录/编者另行统计与导出核对.json`，不冒充模型动作。189-B 首次材料提取曾只取得首段，在模型运行前发现并改用新库完整初始化；错误起点未放入交付包。

本目录包含可直接运行的 `dist/`、固定的 `source-version.json` 和文件清单。它不包含数据库文件、私有会话、登录配置或依赖目录。正文来源、业务保存、运行终态、课堂采用与是否发布应分别判断。

本章 10 次新模型任务的原始记录路径见 `materials/本章模型实录索引.json`；实际页面截图见 `materials/界面实录/`。只读这些记录不会触发模型任务。两部课堂采用稿可分别从 `materials/起点/189-A-交付完成.json`、`189-B-交付完成.json` 恢复到工作台。
