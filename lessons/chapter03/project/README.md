# 渐进式披露

共用服务启动后，打开“请求与上下文 → 渐进式披露”。使用页面顶部的模型设置，无需其他登录。

沿用本目录的 `材料包/`：`入口.md` 指向引用规则与目录，`目录.md` 指向30条原文。选择“逐层读取”，点击“运行实验”，展开实际披露过程和运行记录。

实现位于 `labs/requests/src/disclosure/`：

- `materials.ts` 从现有文件读取全文，按固定清单核对哈希。
- `flow.ts` 的 `initialMessages` 只放问题与入口。详细资料由模型选择路径，实际读取后加入下一次请求。
- `routes.ts` 沿用公共模型设置，将本次输入、返回、读取结果和哈希保存在 `.data/disclosure/`。

先检查第一次请求没有目录与原文，再核对每次读取的内容何时出现在后续输入中。回答正确本身不能证明发生了逐层读取。

“提供全文”和“只提供本次摘要”用于对照；摘要现场生成，回答时不附原文。每个条件独立构造消息，失败不自动重试。

历史课堂实录及原始记录保留在本目录；本次接口运行另存记录。这里只学习资料分层与按需纳入上下文，后续小说插件实践会接入成熟 Harness。
