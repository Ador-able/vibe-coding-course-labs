# 自动记忆修稿练习

材料来自《凡人修仙传》C01、C02 原句，出处见[资料目录](../材料包/目录.md)。草稿只替换一个词作为待修正错误，不另编故事情节。

先比较原句与第一次修稿任务，再运行：

```powershell
node ../观察修稿.mjs
```

在本目录运行上面的命令，沿用本节已安装依赖和已有 Codex 登录。脚本关闭旧记忆使用与新记忆生成，只验证修稿及核对后反馈，结果保存在本目录的 `运行记录/`。没有通过完整正文比对，就不发送成功反馈。这里的反馈回复不是自动保存证据。

需要观察自动记忆时，在专用且已登录、记忆存储独立的 Codex 环境中新建会话，使用 `第一次修稿.txt`；检查只纠正“四十”为“三十”后，再发送 `核对后反馈.txt`。按宿主生成时机检查记录，有实际条目后再用 `第二次修稿.txt` 做两个新会话的使用与停用对照。

独立环境没有准备好时，先完成上述修稿与判断练习。不要向日常记忆库写入练习偏好，不复制个人记忆或认证，不用手写条目代替后台生成。
