# 神手谷｜空间与使用变化

## 空间

初入谷时，韩立看见左侧大片药田，右侧十几间大小不一、连成一片的房屋；环视后觉得除来路外看不到其他通往外边的出口。墨大夫给两人安排较小的一间，自己走进较气派的大屋。来源：[原文/C05.md](原文/C05.md)“在山谷的左侧”附近。

练功另有石室。小瓶最初在屋内吸光时，光丝通过唯一开着的天窗进入；封闭门窗妨碍吸光，移到无人空旷处后光团变大。来源：[原文/C12.md](原文/C12.md)。

## 使用变化

- 初入谷：韩立、张铁随墨大夫住下，外人除病伤一般少来。[原文/C05.md](原文/C05.md)。
- 专心修炼时：墨大夫一度封谷，治病也在谷外进行。[原文/C13.md](原文/C13.md)。
- 当前：墨大夫离谷、张铁不在，韩立借独处之机做催药试验。[原文/C13.md](原文/C13.md)、[原文/C23.md](原文/C23.md)。

地点旧时的使用状态不等于当前状态。准备夜间藏瓶时，还要核对[小瓶的具体限制](场景、物品与规则/小瓶/详情.md)。
