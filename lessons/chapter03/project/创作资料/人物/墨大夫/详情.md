# 墨大夫｜设定与变化

## 稳定设定

医术受到门内弟子尊敬。高瘦、面皮焦黄、白发披肩，常咳嗽；说话与行事自有主张，对韩立修炼进度十分在意。

## 重要变化

| 故事阶段 | 变化 | 来源 |
| --- | --- | --- |
| 初入谷 | 以缺炼药、采药弟子为由带走韩立与张铁，安排住处，允许称“墨老”或“墨大夫” | [C05](原文/C05.md) |
| 修炼阶段 | 投入药物与银钱支持韩立，也会训斥、督促 | [C13](原文/C13.md) |
| 四年后 | 病情加重；韩立从其目光中感到不安。得知瓶颈后，墨大夫下山寻药 | [C13](原文/C13.md) |
| 当前阶段 | 韩立估计他回谷前的可用时间，决定不透露小瓶 | [C23](原文/C23.md) |
