# 小瓶催药

当前状态：催药用途已验证，真正来历仍未知；下一步是用有限条件解决药材不足，而不是公开宝物。

## 经过与变化

1. 最初研究小瓶时，韩立发现夜间光丝和绿液，却不知道用途，后来专注练功，一度忘了瓶子。见[章节/第十四章.md](章节/第十四章.md)。
2. 多年后，绿液试验发生意外；溅落药地的液体反而催熟了药草。韩立由“可怕的东西”转为看到突破修炼瓶颈的机会。见[章节/第二十五章.md](章节/第二十五章.md)。
3. 经观察药性、等待放晴和再次凝液，他确认小瓶不是一次性物品；随后测试保存与叠加效果。见[章节/第二十六章.md](章节/第二十六章.md)、[原文/C23.md](原文/C23.md)。
4. 当前他担心怀璧其罪，决定不向任何人透露，并考虑赶在墨大夫回来前准备药材。见[原文/C23.md](原文/C23.md)“自己绝不能把瓶子的事告诉任何人”起各段。

天气或封闭空间再次出现时，早先光点的描写会重新影响行动，沿[小瓶详情](场景、物品与规则/小瓶/详情.md)回查。物品使用规则不在本页重复维护。

尚未解决：怎样在不暴露的情况下满足后续修炼所需；小瓶的来历与能力边界。不能用后来章节的揭示替当前人物作答。
