# 使用规则

- 当前工作页确定故事时间。人物的能力、位置、物品和知情范围取该时点的状态；回忆过去时，沿人物详情中的变化记录核对。
- 资料中的事实、人物猜测与后续计划分别使用。对白只证明人物这样说过，不能直接当作世界真相。
- 日常写作先看相关工作卡；精确承接、旧事呼应、能力限制或资料冲突，沿链接读详情和原文。链接存在不代表内容已经读入。
- 可以补写与已有事实相容的动作、对白和心理。改变既有规则、重要关系或物品归属时，列出需要确认的内容。
- 正文定稿后，同步发生变化的人物状态、关系、认知、物品与剧情线，并把新线索挂到未来会遇到的对象入口。来源和适用进度一并更新；未确认的安排仍保留在计划中。
