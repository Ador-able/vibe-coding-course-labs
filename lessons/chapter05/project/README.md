# 工具与 Agent

从读取资料、生成草稿、实际保存和工具反馈，理解模型怎样连接外部系统并持续推进任务。

## 工具读写

沿用仓库根目录的公共页面和模型配置，打开[工具读写实验](/requests/tools/)。先根据任务选择工具集，运行任务或加载课堂实录，再核对实际工具调用与保存结果。

## 工具反馈

打开[工具反馈实验](/requests/tool-results/)，使用同一页面运行自己的任务或加载本节课堂实录。

1. 查看工具定义与任务，预测需要取得哪些信息。
2. 运行任务；也可以在“任务依据与当前前文”中调整第一章正文，再观察后续行动。
3. 按模型请求轮次查看实际收到的工具反馈、提出的调用与执行结果，最后核对程序独立读回的第二章。

每次运行使用独立工作区，第一章的编辑会实际写入该工作区。完整请求、工具结果与草稿保留在本机运行记录中；课堂实录来自同样的真实流程。

## 比较工作流与 Agent

打开[工作流与 Agent 对照实验](/requests/control/)，使用同一页面运行对照或加载课堂实录。

1. 选择路径已知或根据线索补查的情境，预测三组需要取得哪些依据。
2. 运行对照，依次观察固定基础读取、Agent 自主选择和混合安排。
3. 对照实际读取、完整核对意见与原文，再判断动态选择是否取得了所需信息。

三组共用同一任务、练习稿、资料和模型。两份练习稿用于尝试不同线索；材料为本节编制，不是历史模型生成记录。固定基础读取只是一个基线，不能代表所有工作流设计。完整材料与运行说明见仓库 `lessons/chapter05/control`。

## 人的决定怎样进入下一轮

打开[人的决定实验](/requests/human-decisions/)，在同一页面运行自己的任务或加载课堂实录。

1. 先回答模型提出的方向问题，再核对新要求是否进入接续任务与实际正文。
2. 阅读并采用具体稿件，再修改内容，核对新稿状态与旧版本请求的拒绝结果。
3. 对具体保存请求批准、拒绝或修改参数，再接续并独立读回实际结果。

本节复用公共模型设置，不需要编码助手或额外登录。完整材料、课堂记录与说明位于仓库 `lessons/chapter05/human-decisions`。采用绑定具体内容是工作台业务约定；操作审批则对应本次具体调用和参数，两者分别记录。

## 查原文还是问人

`clarification/original.md` 是现成小说的完整C03片段，`clarification/tasks/a.md` 至 d 是四种短任务。主练习只需将同一份原文和选定任务提供给已有AI工具，不必续写完整章节。

需要保存实际请求时，复用共用模型设置与当前依赖：

```powershell
node ../../../scripts/run-lab.mjs . clarification/run.mjs --case a
```

其他条件只替换末尾字母，不必全跑。结果在 `clarification/records`，原文与任务直接进入请求，入口没有文件读取工具，也不保存小说章稿。错误保留在同轮报告中，不自动重试。

“查资料还是问人实录.html”对应完整实际回复。首轮A/D因1400输出上限而没有最终文本；提高上限后仅各补一次，原记录保留。D随后直接交出包含“正午”的摘要，没有先处理同级冲突；C提出重点选择，但截止地点的表述仍需回原句核对。

## 观察何时继续、求助或停下

打开[继续、求助或停下实验](/requests/agent-stopping/)，沿用公共模型设置，运行自己的任务或加载课堂实录。

1. 选择材料足够、等待作者决定、受控写入故障或取消情境，查看任务与工具定义。
2. 运行后沿实际工具反馈观察进展；需要时展开运行边界，调整模型调用上限或时限。
3. 比较结束原因、尚未完成事项和程序独立读回。取消时对照初始稿与结束后的实际稿件，区分已有成果和本轮新增保存。

本轮任务、模型请求、工具结果和实际数据库保留在本机。完整材料与边界说明位于仓库 `lessons/chapter05/agent-stopping`。
