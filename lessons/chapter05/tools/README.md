# 工具读写

沿用课程仓库根目录的安装、构建与启动，在第五单元打开“工具读写”。页面顶部的模型设置与其他网页实验共用；接口需要支持工具调用。

填写要完成的任务，选择“分散读取”或“组合读取”，点击“运行任务”。不必把两种条件都运行一遍。每次运行都从同一份初态建立独立工作区，不修改上一次草稿；模型自行决定调用哪些工具。

## 工具与资料

- 分散读取：`read_work`、`list_chapters`、`read_chapter`、`save_draft`。
- 组合读取：`get_writing_context`、`read_chapter`、`save_draft`。

作品由应用绑定。当前练习只操作第一章；`get_writing_context` 将分散工具能够取得的同一份作品要求、目录和当前正文合并返回，不增加资料或权限。保存使用已读修订，只返回章号、修订和草稿状态。模型的正文读回与程序独立读回分别展示。

`materials/initial-work.json` 的要求和设定来自相邻 `project/seed/凡人修仙传.json`，大纲保留其第一章目标；C01—C03 原文原样取自 `../../materials/凡人修仙传/原文片段.json`。原作作者为忘语。两种条件使用同一初态文件及其 SHA-256，不根据结果改写资料。

## 调用与状态

网页 → `POST /api/tools/run` → 新建独立 SQLite 工作区 → AI SDK 工具循环 → 业务工具事务读写 → 程序重新打开数据库读回 → 保存本轮完整记录。

请求参数为 `{ "task": "任务正文", "toolSet": "separate" }`，另一条件为 `combined`。接口返回 HTTP 202 和本轮 ID，通过 `GET /api/tools/runs/:id` 读取进度；`POST /api/tools/runs/:id/cancel` 停止后续处理。

每次运行保存于仓库根目录 `.data/tools/<运行ID>/`，其中 `work.sqlite` 是独立教学状态，`run.json` 保留任务、初态摘要、工具调用标识及参数/结果、真实模型请求/返回、已报告用量和程序读回正文。缺失用量保持未知；不保存密钥。页面只展示两种条件的最近结果，较早的文件保留。

不设置输出 token 上限，不自动重试模型请求。过程最多进行20次模型请求，达到边界时明确停止并保留结果。取消或接口异常也保留已经发生的工具操作和实际草稿，不把停止等同于内容不合格；内容质量需要人阅读判断。

## 课堂实录

点击“加载课堂实录”，查看本节使用的分散读取和组合读取两次真实运行。两组都保存了第一章草稿，并在保存后读取正文；组合条件还重复读取了一次已经取得的当前章状态。每种条件只有一次记录，不能据此认定哪种设计普遍更好。

完整实录保存在本目录 `classroom.json`，包含实际任务、初态摘要、模型请求与返回、工具调用和独立读回。`GET /api/tools/classroom` 只读取该文件，不创建工作区、不请求模型；课堂与自行运行共用同一结果组件。
