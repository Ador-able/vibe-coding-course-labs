# 工具反馈实验

沿用仓库根目录的公共页面和模型配置，打开“05 理解工具、工作流与 Agent → 工具反馈”。

1. 查看工具定义与任务，先预测模型还需要取得哪些资料。
2. 运行任务，或加载课堂实录。需要尝试不同接续依据时，在“任务依据与当前前文”中调整第一章正文，再运行。
3. 按模型请求轮次，查看收到的工具反馈、提出的调用与实际执行结果，最后核对程序独立读回的第二章。

每次运行使用独立的本机工作区，前文编辑会实际写入该工作区。模型只通过业务工具读取第一章、创建或更新第二章草稿，不能修改原有第一章。只保存草稿，内容是否采用仍由人判断。

课堂实录位于本目录的 `classroom.json`，包含真实请求、工具调用、返回和独立读回结果。它与自行运行使用同一页面呈现。

材料中的第一章原稿与调整后正文，来自仓库已保留的真实稿件及受控编辑记录。它们用于建立本轮起点，并非新的一次模型生成。
