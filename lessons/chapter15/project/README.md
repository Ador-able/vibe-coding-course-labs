# 凡人原文的已有项目实验

从课程实验首页选择“修改已有项目”，或打开 http://127.0.0.1:4318/lessons/chapter15/ 。查看课堂实录不调用模型；本章命令在当前目录执行。

## 材料与准备

`inputs/凡人修仙传-三段原文.json`保留C03—C05完整连续原文。教学章号不是原书章号。`完整教师初始化.json`将原文、大纲和设定导入新独立作品，保留段首与换行；原作署忘语，初始三段均为草稿。

亲做时先保存自己的源码和数据库，运行`pnpm practice:seed`、`pnpm prototype`。初始化每次使用新库，已有库不覆盖。调查任务先读当前完整对象，只读阶段不安装、不测试或写数据。模型与登录沿用已有Codex，课堂私有配置关闭个人记忆与应用工具。
