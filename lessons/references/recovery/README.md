# 代码、会话和数据的恢复范围

比较文件、个人提交、stash 与业务章稿的恢复范围，不调用模型或启动服务。

1. 先读 [完整实际结果](records/完整实际结果.json) 与 [编辑后五表](records/编辑后完整五表.json)，区分代码和业务对象。
2. 亲手恢复时，在本目录运行 `node ./恢复本次练习.mjs`。它从固定 bundle 建立独立 `project/`，再复制教学业务备份与笔记；已有 `project/` 时停止。
3. 读取新产生的 `本次恢复结果.json`、`本次恢复命令.json` 和 `project/data/recovery.sqlite`，核对个人 HEAD、保留的 stash、164 份源码与第二章 r2。

原始输入、业务备份和代码 bundle 在 `fixtures/`，课堂完整命令及返回在 `records/`。恢复不安装依赖、不恢复模型会话；失败保留当前文件和 `本次恢复失败.json`。教学正文沿用原归档身份。
