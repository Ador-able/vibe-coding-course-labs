# TypeScript 与项目运行

用人工短段落观察外部输入、异步保存、路径、环境变量与 UTF-8 解码，不调用模型。

1. 先读 [完整课堂观察](records/完整观察.json)，对照 [实际保存文件](records/实际保存草稿.json)。
2. 亲手观察时，沿用仓库根的统一准备，在仓库根运行 `pnpm --dir lessons/references/typescript/project observe`。
3. 打开本轮 `project/runs/编号/完整观察.json`，比较九条子进程的参数、输出与退出码。两项教学错误的退出码为 1，不能只看外层命令是否结束。

源码与固定输入在 `project/`，补充示意在 `materials/`。自己的结果写入 `project/runs/` 和 `project/output/`，课堂记录保持。`records/教学记录.bundle` 保留原练习提交；历史说明与字节清单也在 `records/`。
