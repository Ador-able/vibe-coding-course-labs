# 凡人修仙传：调查与委派

A 由主代理自己调查；B 由一个默认子代理独立调查，再由主代理回查原文。两次主任务使用同一份完整材料，分别自然结束；子任务如何创建和返回，以实际记录为准。小说只读，不建立业务数据库。

## 先读已有实录

`课堂记录/凡人原文-20261015/` 保存当前原文实验的输入、结果与核对，阅读实录不需要调用模型。`materials/` 与 `prompts/` 保留本节完整材料和任务。

## 检查本节宿主

完成仓库根的统一准备后，在本目录检查本节宿主：

```powershell
pnpm host:check
```

宿主检查只读取配置与能力目录，不调用模型。配置仅作用于本实验：只读、无联网，关闭记忆和其他插件工具，沿用当前登录和模型选择。检查主会话的配置不能证明子代理只收到任务文本；子代理仍有宿主提供的基础指令。

## 运行两个条件

需要亲自运行时，按顺序各执行一次；已有实录可直接用于后续阅读：

```powershell
pnpm observe --condition A
pnpm observe --condition B
```

每次运行返回独立的 `runs/条件-编号/`。保留完整输入、公开 SDK 事件、计时、消息与结束报告。最多等待十分钟，没有自动重试；失败、超时、无法委派或报告缺失均保留实际结果，不为取得理想答案换一种方法重复调查。

## 查看实际会话

将路径换成刚才返回的运行目录：

```powershell
pnpm inspect --run runs/B-实际编号
```

该命令只读取官方应用接口。先保存主会话的完整可见条目，再按它实际返回的子编号读取对应子会话，不再调用模型。结果在该运行目录的 `session-readback/`。

核对材料是否完整读到、重要结论是否有原句支持、主代理是否实际回查，以及返回是否完整。接口没有返回的内容仍是证据缺口；主会话用量不能充当整个团队用量，运行结束也不能证明文学质量或人的认可。

运行记录使用当前克隆仓库的 Git 提交标识源码版本。账户凭据、私有宿主目录和本地会话存储不属于公开材料。
