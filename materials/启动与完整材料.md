## 恢复自己的固定Git根

在新目录解压，进入05-03-两路检索与原文回查。lab和资料代码.bundle保持相邻。恢复操作只用于这个新解压目录：

~~~powershell
git -C lab init
git -C lab -c core.autocrlf=false fetch ../资料代码.bundle refs/tags/vcm-05-03-start:refs/tags/vcm-05-03-start refs/tags/vcm-05-03-end:refs/tags/vcm-05-03-end
git -C lab reset --mixed vcm-05-03-end
git -C lab rev-parse HEAD
python -X utf8 -m http.server 4346 --bind 127.0.0.1 --directory lab/public
~~~

HEAD是bb5f2838157f13807e1be2fa83ba7439366c4401，起点是e35d02102264529747376941b24aaee4e161b062。浏览器打开http://127.0.0.1:4346/，结束时在自己的服务终端按Ctrl+C。已有public/observation.json、12个public/materials原件、三页原图和原PDF都随包提供；不依赖父项目或原本机绝对路径。

Node24与本项目pnpm锁用于已有SDK/Orama。先在lab执行pnpm install --frozen-lockfile。可指定本包的实际向量报告，只重做本地计算：

~~~powershell
Set-Location lab
pnpm retrieval:rank ../实际记录/embeddings-e273a2bf-4aed-4c2e-bb5d-21a6fb3da732/report.json
~~~

本地排名写自己的新UUID；保持原结果用于比较，不把新记录称旧轮。默认查看不需要这一步。lab/README补充独立新执行的调用范围；不要为打开已有页面先跑embeddings:observe，也不必运行继承的切分、问答或PDF脚本。
