# 启动取消、超时与失败练习

本入口用固定纪要和官方AI SDK Mock观察请求状态，不用模型密钥，不写章稿数据库。原本地八任务的完整记录在“本轮实际观察”；自己复做会产生新身份和时间，停止时实际前缀也可能不同。

环境：Node.js 24.12至24.x、pnpm 11.20.0、Git；依赖锁中的AI SDK为7.0.122。先把整个目录解压到自己新建的独立位置，再在“练习”恢复其自己的Git，不在正在修改的项目运行这些恢复命令。

```powershell
Set-Location './04-04-取消超时失败练习/练习'
git init .
git config core.autocrlf false
git fetch '../vcm-04-04.bundle' 'refs/tags/vcm-04-04-start:refs/tags/vcm-04-04-start' 'refs/tags/vcm-04-04-implementation:refs/tags/vcm-04-04-implementation'
git reset --mixed vcm-04-04-implementation
git rev-parse HEAD
git status --short
pnpm install --frozen-lockfile
pnpm requests:check
pnpm requests:build
pnpm requests:dev --evidence-dir '../我的观察/第一轮' --port 4340
```

完成点HEAD应为`2dbc825c4711f92edb5ecd587ac29ee9261af64f`，起点标签为`3114f6cdc63692e0c33b3eefaab4bbd61241e368`，工作树应干净。reset --mixed建立固定索引与HEAD，保留已解压的原文件，不恢复模型运行或业务状态。所有代码文件在公开清单中按Git原blob字节列出，既有Windows检出换行不能拿来替代原blob检查。

访问 http://127.0.0.1:4340/requests.html 。若4340被其他服务占用，用自己的空闲端口替换--port，不停止其他进程。结束时只在自己启动的终端按Ctrl+C。

页面按七种条件完成八个主任务，具体规则见练习/请求观察练习.md。三方向选择只换布局；“下次材料”和“下次条件”不改变已显示记录。未确认时先人工GET同编号，不自动再POST。服务当前Map只读本次进程，公开旧记录直接读文件，不把服务重开写成原模型恢复。
