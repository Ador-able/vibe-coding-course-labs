# 本轮完整输入与受控回答

A 沿用历史摘要输入及答案，B 由教师构造。本轮用官方 Mock 将固定文字送入真实 SDK/HTTP/页面，不是新模型生成或文学采用。原设计文件的时点措辞保留在固定 Git 材料中。

## 材料 A

### 完整规则

```prompt
只依据工作纪要写一段约120字的简明摘要，区分已确定安排和未决事项。不补造事实，不提出问题，不加标题。
```

### 完整用户原文

```plaintext
青禾社区共享书架筹备纪要（教学虚构）
计划于10月12日下午开放一层共享书架，由林晓负责整理捐赠图书，许宁负责制作借阅说明。
图书仅在社区活动室内阅读，暂不外借；每次开放预计接待20人，使用后请把图书放回原处。
书架和阅读桌已经到位，志愿者值班名单尚未确定，现场开放的具体起止时间还需与场地管理员确认。
借阅说明中的损坏处理方式也尚未讨论。先完成材料整理，再决定是否如期开放，不提前对外承诺。
```

### 完整固定回答

```plaintext
共享书架计划于10月12日下午开放，林晓负责图书整理，许宁负责借阅说明制作。书架与阅读桌已到位，图书仅限在活动室内阅读，不外借，每次限20人，使用后需归位。志愿者值班名单及开放具体时间待与场地管理员确认。借阅说明中损坏处理方式未定。材料整理完成后将评估是否如期开放，暂不对外承诺。
```

## 材料 B

### 完整规则

```prompt
只依据工作纪要写一段约120字的简明摘要，区分已确定安排和未决事项。不补造事实，不提出问题，不加标题。
```

### 完整用户原文

```plaintext
临江街道无障碍地图志愿整理会纪要（教学构造，不是实际会议）
计划于11月8日上午在二层活动室整理社区无障碍地图。周青负责汇总已核实的坡道位置，陈禾负责整理需要复查的路段。
地图先用于街道内部讨论，不公开发布。预计有12位志愿者参加，这只是筹备估计，既不是报名上限，也不是已经确定的到场人数。
目前已确认的资料是四条坡道的位置和测量日期；道路施工可能影响通行，现场情况须在讨论前重新核实。电梯是否全天开放尚未向物业确认。
记录里有两条来源不明的“畅通”标注，应单独列为待核查，不得合并进已核实清单。具体签到时间、志愿者分组、复查人员和对外发布条件都尚未决定。
会议只讨论资料整理，不提前承诺某条路线一定可通行；整理人员应保留来源、时间和未知项，等现场复查后再决定下一步。
```

### 完整固定回答

```plaintext
无障碍地图资料拟于11月8日上午在二层活动室整理，周青汇总已核实坡道，陈禾整理待复查路段；预计12位志愿者参加。资料先供内部讨论。四条坡道已有位置与测量日期，施工、物业电梯开放情况及两条来源不明标注仍需核查。签到、分组、复查人员和发布条件尚未决定，不承诺路线一定可通行。
```

A 原文写预计接待20人，固定回答却写每次限20人；这个偏差没有被清洗。B 不作模型质量比较。分段文件、历史回答来源、未知用量和完整迁移任务在练习/public/requests-fixtures。
