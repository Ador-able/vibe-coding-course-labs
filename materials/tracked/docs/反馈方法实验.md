# 在新任务中使用反馈方法

业务代码沿用固定Store和MCP，Agent由Codex0.160.0承担。新作品只有一个局部场景。人工先保存有钥匙冲突的r1，再只修正钥匙得到r2；旧反馈对应r1，本轮反馈要求保留当前首尾，补写守塔人开门和林澈进入。

```powershell
pnpm install --frozen-lockfile
pnpm build
pnpm feedback:prepare
pnpm feedback:preflight --out runs/feedback-preflight-01
pnpm feedback:preflight --out runs/feedback-preflight-02
pnpm feedback:preflight --directory-only --out runs/feedback-hook-directory
```

prepare通过人工CLI真实保存，遇到已存在的数据库就停止，不清库。预检取得配置、Skills、Hooks和MCP实际目录；空会话随即归档，没有turn/start。首轮若有额外能力，停用项只作用于下一次当前进程，必须再看实际目录。命令行覆盖的点分路径按官方解析器使用真实名称；名称外加的引号会被当成名称的一部分，不会停用原入口。

预检应看到唯一项目Skill和novel_lab的四工具。Hooks目录应只有一个PostToolUse，匹配mcp__novel_lab__save_draft。Hook脚本读取真实保存返回，既不改正文，也不回滚已保存版本；无标记不证明情节或文学表现合格。

主编需要完整核读当前定义、脚本、八份输入和人工基线，再填写runs/feedback-trust-review.json的approvedBy、唯一key/currentHash与本进程overrides。初始模板approvedBy为null，观察入口拒绝执行；旧项目的信任key不能代替当前项目审核。审核后文件SHA与实际trusted目录还需一致。公开包不提供账号或全局配置，也不写全局信任。

仅在本次主编批准后，才使用下面的真实任务入口：

```powershell
pnpm feedback:preflight --trusted --out runs/feedback-trusted-directory
pnpm feedback:observe
```

观察器只发送一条官方turn/start，不代替AI决定业务动作，也不续发纠正任务。最多新增两版是给模型的软要求；取得turnId后五分钟请求官方interrupt，再等真实终态。未确认终态时不改称取消成功。记录保留原始错误、完整业务对象、全文和实际Hook结果。

模型shell使用read-only以允许读取方法和反馈；这并不禁止已授权MCP保存或已信任Hook写日志。网页、记忆和项目说明注入关闭。目录预检只证明可见入口；核心、条件参考、两份反馈是否真的被读取，须看真实任务事件。首尾是否保留、旧反馈是否仍适用、补写是否符合目标，须读实际保存全文。表达取舍和采用继续由人决定。

本实验没有无Skill对照，不作效率或质量的因果排名。公开记录不收录宿主system/developer、身份和记忆受保护正文；只保留本实验教师输入、Hook反馈与实际结果。完整原始配置目录保留在本地审核范围，不直接混入课程下载。
