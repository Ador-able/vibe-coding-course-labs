# 让 Agent 用工具产生真实改动

这里保留同一作品从两章草稿到第三章局部修订的真实课堂材料。小说只是 AI 使用实验：比较方案、保存人的决定、根据当前资料写稿，再让针对实际稿件的意见进入局部修改。

三轮自然任务分别有 20、26、26 条 SDK 事件。它们各是一轮自然任务，可能含多次模型请求；事件记录没有给出逐请求次数。A 只提两条路线，B 保存完整第三章，C 只替换人的当前选区。两次人的决定出自课程编者，不表示课程用户已选择或采用小说。第三章当前 r4 是草稿；历史 r2 曾作课堂演示采用，r3 保留人的末段修改。

## 先阅读实际材料

- `records/A/formal`、`records/B/formal`、`records/C/formal`：完整 input、events、before、after、final-response、report、archive，原字节保留。模型输入、工具参数和完整返回均在其中。
- `records/A/window`、`records/B/window`、`records/C/window`：各轮冻结输入、真实命令、窗口回执、九个已安装插件文件原件和一致备份。安装恢复只保留元数据，不含私人配置正文。
- `teacher`：完整教师请求、实际 H1/H2 决定、人的选区与任务建立入口。决定文件中“之后才准备”等句子属于当时的真实输入，不能当成后来步骤尚未执行。
- `records/H1`：资料更新真实命令、输入、返回和前后五表；仅改变用途并追加第三章目标。
- `records/H2-adopt`：真实采用入口与返回，说明分隔中的字面量 `\n\n` 也保留。它是这次实际返回，不推出所有 Windows／pnpm 调用的原因。
- `records/H2-ui`：同一次真实页面末段编辑、POST 全参数／全返回、r3 完整读回、三方向十八幅状态图及导航。
- `records/C-ui`：正式 r4 的三方向当前稿、资料展开、窄屏九幅只读图及导航，没有再次保存。
- `records/zero-model`：官方 Client 的九组独立 UUID 实验，完整协议、人工参数、返回、前后五表和备份；与自然任务的实际错误分开。

图片记录整页和完整编辑 value，不表示整章所有字同时可见。原版、台面、笔记页保留相同业务；功能、操作辨认和整体口吻分别比较，没有自动选赢家。

## 不调用模型，查看当前稿和完整历史

用 Node 24.12.0 或满足项目声明的版本，pnpm 11.20.0。依赖写在项目和锁文件中；安装只发生在独立目录。包名是 agent-practice-lab。

在解压根目录运行：

```powershell
git clone .\真实改动.bundle .\practice
Set-Location .\practice
git checkout --detach vcm-07-03-end
pnpm install --frozen-lockfile --virtual-store-dir .pnpm --package-import-method copy
pnpm build
New-Item -ItemType Directory -Path .\data -Force | Out-Null
Copy-Item -LiteralPath ..\records\C\window\正式后一致备份.sqlite -Destination .\data\current.sqlite
pnpm lab show --db data/current.sqlite --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea
pnpm lab chapter 3 --db data/current.sqlite --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea
pnpm prototype --db data/current.sqlite --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea --port 4337
```

打开 http://127.0.0.1:4337，在同一页面切换原版、台面、笔记页。页面与 CLI／MCP 共用 Store，不另导入页面正文。这条路径没有模型调用或插件安装；按 Ctrl+C 关闭服务器。

## 可选：在独立 r3 备份里复做局部修改

这是新的实际运行，不复演为历史 C。先完整阅读人工 r3，决定是否仍接受原意见。若改了意见、稿件或范围，就重新绑定当前原文和基线，不能只提高旧修订号。任务、模型会话和采用是不同对象。

下列入口使用包内真实 C 前置备份：其中 C Task 是 created/null，业务状态为人工 r3。每次使用一个新的副本路径，保留历史材料不动。需要本机已经具备可用的 Codex 登录与模型权限；课程网站登录不是该宿主登录。

从 `practice` 目录运行：

```powershell
Copy-Item -LiteralPath ..\records\C\window\正式前一致备份.sqlite -Destination .\data\excerpt-practice.sqlite
pnpm lab chapter 3 --db data/excerpt-practice.sqlite --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea
pnpm plugin:prepare --db data/excerpt-practice.sqlite --task ca965925-bd81-445a-871f-59eb53b4c6f0 --excerpt materials/人工选区-C.json
pnpm plugin:add
try {
  pnpm plugin:preflight --out runs/目录初查
  if ($LASTEXITCODE -ne 0) { throw '目录初查失败，请保留原记录。' }
  pnpm plugin:preflight --out runs/目录确认
  if ($LASTEXITCODE -ne 0) { throw '目录确认失败，请保留原记录。' }
  $check = Get-Content -LiteralPath .\runs\目录确认\report.json -Raw | ConvertFrom-Json
  if (-not ($check.isolated -and $check.skillsIsolated -and $check.memoryIsolated)) {
    throw '本轮实际目录未满足运行条件，请先读完整报告。'
  }
  pnpm plugin:observe --db data/excerpt-practice.sqlite --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea --chapter 3 --prompt materials/任务-C.txt
} finally {
  pnpm plugin:remove
}
```

初查取得目录并保存本轮停用项，再确认实际两项方法与五工具；不要只凭第一次 exit 0 就接观察器。目录中的两个方法并不保证模型都采用。本次正式 C 实际只读取章节写作方法和一份参考。

新增动作只有 revise_excerpt，模型只提交 replacement。人工绑定含作品、章号、UTF-16 `[719,805)` 原文、资料 r3／本章 r3／前文 r2 和 r1；工具保留当前标题和两侧原文，复用 Store 的保存事务。启用目录不含 save_draft。项目仓库规则自动注入关闭、记忆使用和生成关闭，不等于宿主全局用户规则被关闭；受保护规则只记录来源路径，不含正文。

这条可选路径会临时安装自己的插件；不要同时运行另一个安装窗口。finally 官方移除本轮安装，不写回课程作者的私人配置或历史 SHA。若当前用户或宿主有外部配置变化，应保留它并核当前相关键。模型结果、成功／失败和已发生保存都按实际 records 记录，不自动再跑，也不把取消解释成撤回先前保存。

若要自己完成 A／B 的新流程，从开始备份和相应标签开始，先运行提议，读实际输出并作自己的选择，再经现有 CLI 更新资料。`teacher/create-task.mjs` 是 Store.createTask 的薄教师入口，使用新的 UUID；它不调度模型或制造成功状态。生成之后才作具体稿件意见，再准备 C。
