## 自己运行一次续写

inputs/完整任务.txt是本次实际完整任务；materials/来稿中两份来稿是明确标记的人工课堂输入，不是用户文学决定或历史模型结果。本节实际任务使用这个完整输入，不补造一个“更好结果”的输入。

先确认同名练习插件没有被其他任务使用。插件绑定必须指向自己当前目录和数据库；缓存不自动跟随移动的项目。

```powershell
pnpm plugin:prepare --db data/context.sqlite
pnpm plugin:add --output runs/插件安装.json
try {
  pnpm plugin:preflight --out runs/能力前检
  pnpm plugin:observe --db data/context.sqlite --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea --chapter 2 --prompt inputs/完整任务.txt
} finally {
  pnpm plugin:remove --output runs/插件移除.json
}
```

前检取得能力目录和实际配置，不发送模型任务。本包实际安装缓存9文件、四业务工具和两项Skill均核过；能力目录不足、资料不全或前置失败时先检查真实返回，不先运行模型。模型任务仍须按实际结果判断，不保证每个人得到相同文字。

固定参数关闭仓库项目规则自动注入及配置中的记忆能力，不能因此推断全部宿主背景被排除。Codex0.160的全局用户规则提供器仍可能参与，实验只记录来源路径，未读取或公开受保护正文。正常个人配置与真实来源须按实际情况解释。不要把isolated等前检标签扩大成“只剩任务和Skill”。本节不依赖自动记忆成功。

SDK入口只发一次自然任务，保存公开完整输入、事件、参数、返回和前后状态。Ctrl+C把AbortSignal交给成熟SDK；取消不撤回已保存业务，结果未知时先回查。该接口支持取消，但本次正式任务正常结束，没有取消实测。不要把这段运行说明写成已发生的中断或网络失败。

## 怎样判断这次结果

第二章引用作品r2、第一章r2，真实保存为r1/agent/draft。首章basisCurrent=false仅表示它引用旧作品资料版本；第二章true表示引用当前版本。版本关系不能证明全文语义正确、文学认可或已被采用。章节taskId/threadId为null，因为该入口未调用业务createTask；Harness thread ID在观察记录，不补写到章节。
