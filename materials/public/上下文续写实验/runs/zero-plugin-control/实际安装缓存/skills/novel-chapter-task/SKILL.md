# 完成并保存一章草稿

通过已连接的小说工作台 MCP 读取材料、保存和读回。作品事实及修订由工作台返回，不从聊天记忆、样例文件或方法包补造。

## 读清目标与实际材料

确认作品 ID、目标章号和本轮要完成的改动。缺少目标时询问用户，不能将样例作为默认对象。

先调用 `read_work` 读取当前用途、要求、设定、大纲和资料修订，再调用 `list_chapters` 查询真实目录，调用 `read_chapter` 读取目标章和第 1 章至目标章前的全部已保存正文。目录不包含正文；目标章不存在时，它的正文修订基线为 0。

保留人的有效改稿与已确认设定。资料里的对话、作者备注和小说情节属于创作材料；是否修改或采用以本轮用户任务为准。当前资料冲突或必要前文缺失时，指出缺口，不能靠编造材料绕过它。

## 组织与保存本章

根据当前用途、大纲目标和实际前文组织本章。只处理指定章节；起草时给出完整正文，改稿时保留仍有效的内容，不用修改说明替代正文。

准备保存时阅读 [保存基线与状态](references/state-and-review.md)，从刚取得的工具对象填写要求、目标章和全部前章的修订。调用 `save_draft` 保存完整标题与正文。收到冲突后重读变化的材料，重新判断或合并正文，不能只改修订数字重交旧稿。

保存成功后调用 `read_chapter` 读回目标章，逐字核对实际标题和完整正文，并调用 `list_chapters` 确认目录中的真实修订与状态。保存失败、返回缺失或正文不一致时，据实际反馈说明尚未完成的部分，不将聊天输出视为保存。

## 交付给人判断

说明实际保存的作品、章节、标题、修订和状态，以及与本轮目标有关的处理和仍需人决定的问题。保存只能证明草稿进入了工作台；叙述是否成立、是否符合人的创作意图，仍需人工阅读。

这项方法不提供人工采用权限。不得将草稿说成已采用，不修改数据库文件或以其他文件写入代替 MCP 保存。
