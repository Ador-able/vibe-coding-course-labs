本材料复用成熟Harness、现有Store、CLI、MCP、两份方法与三种工作台页面。课堂新增的是两轮只读终审、编者实际取舍、人工保存/采用和准确全文导出，不重新开发Agent循环。

- `vcm-07-08-review-start` / `d99e74888bbc7a5a073710c54f871a2096b62376`：本节正式终审代码/两份完整输入与新教学三章材料固定点。`business/start.sqlite` 为正式零写入起点，五表2/5/7/12/8。

## 在独立副本读取和人工练习

需要Node24.12或以上，以及本项目锁定的pnpm11.20。不要改锁、全局安装依赖或覆盖前置课堂库。在解压后的`project`目录执行：

```powershell
pnpm install --frozen-lockfile --virtual-store-dir .pnpm
pnpm build
New-Item -ItemType Directory -Path data -Force
Copy-Item -LiteralPath ../business/start.sqlite -Destination data/my.sqlite
pnpm lab show --db data/my.sqlite --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea
pnpm lab chapter 4 --db data/my.sqlite --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea
pnpm prototype --db data/my.sqlite --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea --port 4348
```

打开`http://127.0.0.1:4348`，选择第四章。页面底部原版、台面、笔记页共用同一稿件与操作；选择适合自己的方向。本次页面比较的实际范围在`pages/同稿三方向与真实人工链判断.md`，三方向没有优胜结论。原版取得一幅整页图，其余视口帧加完整DOM/value保留实际观察范围；没有三份全文同屏图。

人工阅读终审原答后决定保留、编辑或不采用。若编辑，先重新读取当前稿，保存成功后核对全文；复制课堂决定并不等于你认同文学选择。采用入口是CLI，编辑页仍只有“保存草稿”，没有新的自动采用按钮。例如，先查询自己当前修订再执行：

```powershell
pnpm lab chapter 4 --db data/my.sqlite --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea
pnpm lab adopt 4 --expected-revision 3 --note "已实际读完当前第4章；选择保留开放谜题，并交付本次查证行动。" --db data/my.sqlite --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea
New-Item -ItemType Directory -Path deliverables -Force
pnpm lab export deliverables/my-四章.md --db data/my.sqlite --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea
```

上例的3只适用于你确实完成那次人工保存、当前第四章为r3的情况；不能拿旧基线重复采用。拒绝采用时保持draft并记录需解决的问题。本章真实采用输入和每次完整返回在`adoption/A`与`adoption/B`，读者自己的决定和版本可能不同。导出目录需先存在；CLI写文件失败不能当成没有已保存稿件。

要查看最终已采用成果，另复制`business/current.sqlite`至新的本地文件后用相同CLI读取，或阅读`project/deliverables/`两份真实导出。不要为了演示覆盖自己的工作库。

## 接续成熟宿主做自己的终审

`teaching/delivery/A-完整教师输入.txt`和`B-完整教师输入.txt`是本章实际输入原件。两份方法在自主插件的skills目录，业务MCP入口是`dist/mcp.js`，绑定需要明确数据库路径。正式任务只开放`read_work`、`list_chapters`、`read_chapter`、`export_work`四项读取工具；`export_work`返回全文，不写文件。由已配置的成熟客户端加载本地方法与这个MCP，再交完整目标和对象ID；不要把B故事当作新模型生成。

本包中的历史SDK输入、目录与观察器记录绑定了本次作者目录、缓存和实际对象，不是跨机器免配置命令。不要原样执行作者绝对路径或历史审批文件，也不要为复做写回共享配置。先在自己的独立项目设置入口、数据库、宿主账号及必要目录，确认实际方法/四工具；所用现行版本不同须按其真实文档核对。模型与推理强度未由本课覆盖，两轮SDK统计是实际运行累计用量，不是上下文窗口或一次API调用。

## 完整证据与边界

`records/A`与`records/B`保留完整教师输入、所有SDK事件/工具参数/返回、方法及参考读取、原最终答复和前后完整五表。`business`另存正式起点、人工保存后、采用后和最终阶段的真实一致SQLite备份，不声称每次SDK运行都生成了前后SQLite文件。A30事件、六次业务读取；B26事件、五次业务读取，均正常完成并归档，没有写业务对象。两轮都没有实际调用`export_work`；A原答对“取得规范全文”的自述不能补成工具动作。真正写出文件发生在之后的CLI导出。

`materials`保留编者真实取舍、完整人工输入、修改范围和回读核对；`pages`保留真实人工网络请求/完整返回和同稿页面；`adoption`保留每次采用的完整CLI参数/说明/返回、各章回读及准确文件导出。新《最后一只书箱》三章是教师构造并人工初始化，只重跑终审—人工取舍—采用—导出，没有重新验证三章模型生成。故事中的电话、照片、签名和分馆点收属于虚构内容，不是现实业务接口。

准备阶段目录01因当时缓存检查未取得九个文件而失败，随后九文件已实际形成；未修改缓存或重跑模型，目录02按实际原件确认通过。作者检查器误判返回对象形状、URL缺少work参数和网络缓冲全历史范围的失败也保留、明确分类，不冒充自然任务失败。H2网络日志只能证明其中两次POST的完整参数和返回。

目录/归档公开协议是单独投影，省略账户/远程控制通知的值及非教学配置结果，内部原协议保持原字节。包不含共享配置正文、受保护规则、凭据、私有记忆、私有rollout或完整第三方研究；第三方材料只给实际定位、摘要和阅读范围。当前adopted字段记录本章编者课堂选择，不是课程用户采用、出版或发布。文学判断、业务字段和真实文件必须分别核清。
