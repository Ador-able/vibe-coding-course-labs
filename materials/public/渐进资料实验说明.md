# 按需读取资料实验

用同一份虚构资料，比较全文直接提供、只给人工摘要、从入口逐层读取三种输入。练习只核对第4章开头一句话，不写小说正文。摘要由人预先写定，不是另一轮自动压缩结果。

## 准备

解压课程附件，在解压目录执行 `git clone 渐进资料实验.bundle gradual-material-lab`。进入仓库后执行 `git switch -c my-materials vcm-03-05-end`，再执行 `pnpm install --frozen-lockfile`。需要 Node.js 24 以上、Git 和 pnpm。项目使用 Codex SDK 与项目内 CLI 0.160.0；认证沿用你自己的已登录 CLI，按所用账户规则计费。

## 运行

运行 `pnpm experiment`，依次得到 full、summary、tiered 三组完整记录；也可以运行 `pnpm experiment --condition tiered`。脚本为每个条件创建新会话，保持只读目录、never 审批、禁用网络搜索，不实现自己的模型执行循环。结果写入运行记录，每组保留实际输入、输出和公开事件。模型没有显式指定，公共事件没有型号标识时不自行补全。

先逐份核对原文与返回范围，再检查结论是否得到依据支持。工具启动失败不等于资料不存在，完成事件不等于用料核对正确。不同组提供的材料与读取次数不同，不能把单次用量或时间当成稳定效果排名。

## 固定起点与完成点

`vcm-03-05-start` 提供固定资料与契约，可手工沿入口核对；`vcm-03-05-end` 增加真实 SDK 调用脚本和记录。需要重新练习时先保存自己的修改，再从标签建立新分支。Git 只恢复本仓库文件，不恢复认证、费用、服务状态或外部会话。
