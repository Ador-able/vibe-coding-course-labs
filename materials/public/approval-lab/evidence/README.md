# 公开实验记录

本目录记录编者在独占教学数据库中作出的决定与实际 SDK 执行，不是用户文学认可，也不是对外发送或发布。任务标识和模型生成文字是本次可核查的教学材料。

实验顺序与验收条件在模型调用之前确定，见《动作审批实验顺序与验收.md》。场景一检查未批准、退出入口、重开读取与明确拒绝；场景二检查原 A 已批准但尚未执行、改变具体参数、原生拒绝关闭 A、真正新提议 B、旧批准拒绝、独立批准 B 与保存全文读回。

原生动作审批完整核对.json 汇总结果。动作审批-*.json 保留完整待决对象、人工决定、命令退出码及独立业务读回。runs/ 保留这六次普通 Provider 请求的教学正文、响应与 SDK 事件；没有 Authorization 请求头，没有模型凭据。

可在项目根目录执行 node evidence/核对实验.mjs，重新核对公开记录之间的对应关系。这个命令不调用模型，也不写业务数据库；输出仍标明编者核对，不代替另一个人独立运行入口。

实际模型调用发生于提交 1b372cc2b30ec3378ee5318e504d6d41608d9784。最终存档提交仅增加这些证据和运行说明，审批实现没有改变。固定环境为 AI SDK 7.0.127、@ai-sdk/openai-compatible 3.0.62、百炼 qwen-flash。Provider 配置来源只记录本轮后端的非秘密路径；真实配置文件不包含在存档中。

模型最后的普通文字仍说“等待人工批准执行”，但是 SDK 已成功执行 B，没有新增原生待决请求，独立 chapter 已读到 r1 draft 的完整正文。关闭 A 时的普通文字也自行描述了一个新参数对象；它没有形成原生待决请求，入口没有把这段文字当成 B。完整原始记录保留了这些不理想的表现，不能靠模型自述判断状态。

本实验提供结束一次调用后的待决持久化和重新打开；不把它当成完整的任务崩溃恢复系统。若请求在保存以后失败，应先读真实业务状态，不自动重放写入。
