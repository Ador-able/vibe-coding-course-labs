# 让人看得懂，才能作出决定：练习材料

## 先做什么

先读“第一章完整正文.md”和“当前任务.md”，再比较“两份情节方案.md”。本节要决定的是第二章第一段调查怎样展开；两份方案尚未采用，第二章也还没有写出。

写下你采用、修改或退回的具体内容，以及这一决定对下一份草稿的范围和影响。随后，把同一份材料交给另一位学习者，请对方复述要决定什么、依据是什么、下一步会发生什么，并直接改出一处内容。没有同伴时，可以稍后自己重新阅读；这不等同于已经做过真实读者测试。

## 文件各自是什么

- 第一章完整正文.md、背景材料.md、当前任务.md：与上一节 C 条件真实运行完全相同的课堂输入。小说由编者构造，不是现实调查。
- 两份情节方案.md：本节编者准备的完整候选方案，尚未采用；不是两篇完成的第二章，不是本节新调用模型所得。
- 上一节实际待选回复.txt、上一节运行记录.json、上一节完整事件.jsonl、上一节输入记录.json：上一节 C 条件的实际输出及过程。模型指出第一章并未确认窗闩松动；它没有代选方向、续写或采用第二章。过程先有一次命令工具启动失败，随后由可用的读取工具实际读到三个文件；不要把这组环境可用工具视为所有 SDK 安装的默认能力。
- 活动文案真实记录.json：独立的历史活动文案实验，运行编号89c9caf7-09d3-4ca9-a449-b958eb745a5d。包含同一组活动事实、两份实际模型文案与人工修改稿。它与小说不是同一次实验。
- 提示词.txt：可直接复制到自己正在使用的 AI 中，请它重新组织判断材料。需要先附上第一章和当前任务；没有文件上传入口时，可把两份文件全文贴在这段提示词之前。
- 文件校验.json：这个材料包各文件的大小和 SHA256。它用于核对材料是否完整，不证明文学质量或实际采用。

本包没有 API 密钥、私有配置或业务数据库，不需要安装程序即可完成主练习。发送材料到你自己的 AI 服务会按所用服务计费；只读和手工修改本包不产生模型调用。
