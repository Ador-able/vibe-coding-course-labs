## 可选复跑自然任务

阅读上述原件即可完成证据分析，不要求再次发模型。复跑需要自己的可用 Codex 登录或配置。先确认同名练习插件不被另一任务占用，备份自己的原配置；移动仓库后通过 prepare 更新本地 binding，再用官方 CLI 安装。

```powershell
pnpm plugin:prepare --db data/practice.sqlite
pnpm plugin:add --output runs/本次插件安装.json
try {
  pnpm plugin:preflight --out runs/目录初查
  pnpm plugin:preflight --out runs/目录确认
  pnpm plugin:observe --db data/practice.sqlite --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea --chapter 2 --prompt inputs/tools-readonly-task.txt
} finally {
  pnpm plugin:remove --output runs/本次插件移除.json
}
```
