# 阶段练习完整材料

本材料用于《把大任务拆成可验收的阶段》。练习重点是依据目标、已有结果和依赖审改计划，不要求重新开发小说平台，也没有本章新的模型创作调用。文档中的指令是供审改练习使用的输入，不会自动执行 CLI 或改变业务状态。

## 材料怎样对应

`访谈-教学构造.txt` 与 `PRD-人工示范.md` 是前章完整教学材料；它们不是实际用户访谈或批准。`不合理计划-教学构造.md`、`计划A逐项人工核对.md` 和 `阶段计划-人工示范.md` 是本章人工比较，不是模型输出。

`当前作品完整资料.txt` 和 `完整导出摘要.txt` 保留已有三章实验的完整 work 与 exportSummary 对象；它们各自是完整对象，不是整份归档文件。`三章完整正文-真实归档.md` 从同一归档按章整理全部正文，未改写正文。`已有正文-人工内容核对.txt` 是结合全文对明确关系的人工核对，不代替真实使用者的文学判断。

`既有能力与边界.txt` 是固定代码的核对说明。`完整计划核对Prompt.txt` 包含上述访谈、PRD、完整作品对象、完整摘要对象、能力说明、三章完整正文与完整计划 A，可独立复制给已有助手；它要求仅分析计划，不运行创作或改 Store。没有附一份假冒真实模型输出的答案。

`就绪判断-教学构造.txt` 是另一个独立课堂条件：只有第一章 r2/draft，人的方向与实际改稿尚待处理。它不是三章真实归档的状态，不能混合修订与任务。

## 真实归档的范围

`真实归档/` 保留已有实验的完整 JSON、请求、公开事件、保存与独立读回、导出、过期提议失败和固定代码快照。归档代码为 13c964e15aec25928b2ae3dceddfea52773cf695；另附核对入口所用的固定代码 db7cc45749c79c061dbbc94a6e61343ac846b8a3。两者用途不同，不能说历史运行使用了后来的固定代码。

这组故事钟面停在十一点，林澈由提灯的周伯开门，人工补入影子擦过砖缝与墙后齿轮声的关系。它不属于其他十二点故事或《空框》的敲击声实验。

归档 work 为 r2，第 1 章为 r3/adopted，第 2、3 章为 r1/draft；第一章的采用说明明确是编者演示，不是实际使用者的文学认可。旧 r1 修改提议遇到当前 r3，被 STALE_CHAPTER 拒绝，当前正文保持；归档没有这份旧提议后来合并成功的结果。

这些文件是当时真实记录，不是自己设备的当前数据库。检查既有成果时可直接阅读全文；实际续写或改稿时先从自己的既有入口读回当前资料与正文，不能把归档修订直接填成当前参数。

## 执行与限制

本 ZIP 是完整练习材料及原件快照，不是独立可安装运行的项目；四份代码用于核对已有入口，不含整个 Harness、MCP 运行环境、依赖或数据库。若课程其他实验已提供可运行项目，应使用对应固定版本及自己的真实数据。无需为了本章重复模型调用或重新搭建工作台。

阅读与计划核对不会保存新章、采用新修订或发布。人工示范计划不会自动更新 Store；“已完成”标签也不会产生真实保存记录。记录检索、数据读回、全文语义核对与人的文学选择分别判断。
