## Windows 本地入口

使用 Node 24.12.0、pnpm 11.20.0。下面在解压包的 project 目录执行；它沿已有 CLI/HTTP，没有安装插件、创建模型会话或使用课堂观察器。

```powershell
pnpm install --frozen-lockfile --virtual-store-dir .pnpm --package-import-method=copy
pnpm build
New-Item -ItemType Directory -Path '../practice' -Force
Copy-Item -LiteralPath '../states/最终一致.sqlite' -Destination '../practice/当前.sqlite'
pnpm lab show --db '../practice/当前.sqlite' --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea
pnpm lab chapter 3 --db '../practice/当前.sqlite' --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea
pnpm lab export '../practice/三章待审.md' --db '../practice/当前.sqlite' --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea
```

选择一个当前空闲端口。下面以 4337 为例；先检查是否被占用，若被占用，在自己的输入里明确选定另一个空闲端口，不沿用原课堂 Task 或把失败偷偷改写为成功。

```powershell
pnpm prototype --db '../practice/当前.sqlite' --work harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea --port 4337
```

从启动输出取得实际地址，查看第三章。原版：`http://127.0.0.1:4337/?work=harness-02f7db59-e6a1-4e9a-8c4d-75adfa2a1fea&chapter=3&variant=original`；台面将 variant 改为 desk，笔记页改为 notes。三方向仍共用这一库。当前草稿没有本地修改时，保存按钮禁用；查看和导出不等于采用。

这条命令提供持续服务，不要仅等它自动退出。结束阅读时，在启动它的该终端按 Ctrl+C，再看该动作是否退出、地址是否还能访问、保存的导出是否仍在。若通过现成 Harness 启动，则使用它针对该任务的停止入口，并检查对应原最终返回与实际状态；不要按名称批量结束其他 node 过程。

这里是可复制入口，不声称用户机器已经执行或产生本课相同 PID/时间。新机器是否安装成功、页面可访问或停止成功，以自己的实际返回判断。本课固定代码在作者与主编环境已按锁安装、构建并真实执行过；打包后没有再为相同代码启动新宿主、模型或 UI。

## 固定观察器的范围

scripts/observe-command-states.mjs 保存本次完整教学链。它读取主编当时的固定定义回执，核实际源码/依赖与正式五表，使用 config 中本机绝对 cwd、过程标识与原前检路径。因此 fresh clone 的 `pnpm command:lesson` 不是通用重放入口。

公共材料保留原观察器与完整 input 内的回执作为实际原件。这份回执只对应当时的固定环境，不能代替新环境的定义。学习者可以在成熟客户端里执行自己的有限命令并对照 records；若要另做完整状态实验，需要自己明确新库/新 Task/新 processId、实际路径、端口和需要核对的产物，不把本次返回登记成新结果。底座仍由现成执行和取消能力承担。

## 输出、数据库和停止证据的限制

command/exec 的全部实际 Base64 增量、解码输出和原最终返回保留；成功同步辅助 execFileSync 没有单独捕获 stderr，因此不把 helper-commands.json 称为逐通道完整日志。

公开数据库使用 Node 官方 backup 得到的独立一致文件，逐份全五表与实际记录核同。没有把整个 MCP/HTTP 查询过程描述为自动锁住全部任务状态，也不从 backup 的相同内容推断活动数据库/WAL 在整个运行期物理字节未变。

停止只核本次原 pending、terminate 控制响应、原 exec 最终结果、记录的实际身份和端口、完整保存文件与具体 B。A-stopped 三幅是同一 Edge 原生连接错误，应用未载入，不能拿它们核内部错误布局；没有验证写入中停止、自动撤回、全机或全部后代进程清理。

没有把 project_doc_max_bytes=0 解释成隔离全部宿主规则。公共记录只保留本轮必要非秘密运行项与共享配置 SHA，不包含个人规则正文、私有记忆、凭据或整份共享配置，也没有配置恢复/写回动作。
