# 方法与业务入口组成的插件练习

本包用于学习怎样把已有 MCP 和任务方法交付、发现、加载并核对真实业务反馈。小说是练习载体。

## 恢复项目

需要 Node.js 24.12.0、pnpm 11.20.0、Git。包内版本清单记录真实起止与每轮代码。

```powershell
git clone --branch vcm-08-05-end course.bundle lab
Set-Location lab
pnpm install --frozen-lockfile
pnpm build
```

完成点为 5bc3d274985350eeb0b4e3a9b0d74e050e121fa6，起点为 8e095ac7af52d3f61608118af94f82d1c5015ef0。恢复的是代码、锁文件和前节既有成果；本节运行证据与实际数据库在包外层另列。移动项目后按 lab/README.md 重新构建、绑定和安装本插件。插件安装不自动安装项目依赖。

## 先读证据，再决定是否新运行

实验索引列出六轮真实运行，包括 Codex 输入偏差与隔离复做、另一宿主首次 403、Flash 短稿和同会话人工反馈、Plus 独立任务。全部业务正文保留，未人工改写成达标稿。公开 SDK / 原生事件并不等于私有宿主所有输入字节。首次 Codex 的全局记忆命令输出已省略，仍保留命令、状态、调用事实、原文件与省略输出摘要；该事件文件明确是公开投影。目录检查中的其他方法描述和无关工具 Schema 也作投影。隔离复做与其他原生模型事件原字节保留。

只读诊断目录由操作者执行，不计入自然任务的实际方法采用。最后交付目录检查只经过官方 app-server，没有调用模型或业务工具；初查失效、两次稳定及配置恢复分别保留。安装缓存九文件核对是最后纯目录阶段，不能冒称前次模型运行的缓存原始取证。

各证据目录中 before/after.json 是完整五表对象；业务数据库是当时或最后真实状态。Flash 共享数据库现为人工反馈后的 r2，首次 r1 的当时完整对象在第一次 after.json、真实工具返回和后来的章节历史中。恢复业务库时复制到自己的实验 data 目录，再用现有 `pnpm lab chapter 1 --db 数据库路径 --output 输出路径` 读取，不要覆盖自己的作品。403 对应数据库没有章节。

## 自己运行时的条件

Codex 插件入口及官方移除见恢复项目 README；先确认同名插件没有被其他工作使用。实验只临时安装本插件，本进程覆盖其他工具/技能/记忆，结束由官方入口移除。目录三项隔离必须成立，不能只看配置文件。

另一宿主使用 OpenCode 原生 MCP 与 Agent Skills 配置，不是直接安装 OpenAI plugin.json。当前默认 qwen-plus、北京百炼入口；密钥只从自己已有授权文件的 API_KEY 进入当前子进程，包内没有密钥、登录、认证数据库或账号。模型调用可能产生实际费用；没有自动重试。32K/4096 是本次预算，不是最大规格。模型与本地参考宿主指引共同调整，不作严格因果归因或模型排名。

本节不实现模型或工具循环，不生成 Hook，不证明长期任务和中断恢复。事实、修订和采用继续由原 Store 管理；保存草稿不自动采用。
