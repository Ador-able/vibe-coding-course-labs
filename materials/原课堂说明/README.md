# AI 输入缺口练习

本练习用成熟 Codex SDK 启动四个独立会话，读取同一份完整小说第一章与背景，只改变当前任务说明。它观察可查事实、目标未定、偏好未定和要求冲突时的实际处理，不用于估计可靠率或评价文学品质。

入口依赖 Node24.12.0、pnpm11.20.0、Codex SDK与CLI0.160.0。需要按官方方式已有CLI登录；本项目不存认证文件或密钥，也不需要复制任何认证文件。

在本目录运行：

```powershell
pnpm install --frozen-lockfile
pnpm run materials
pnpm run run
```

`materials/` 和 `frozen-inputs.json` 保留完整输入。四个会话使用同一CLI、低推理投入、只读文件、关闭网页搜索，不配置具体型号；实际型号没有确切记录时，不根据当前默认值推测型号。模型只能依据本轮提供的课堂信息，不调用小说业务MCP，也不保存作品正文。

运行记录在 `runs/日期时间/`。每个条件保留实际完整输入、全部公开事件、最终普通回复与报告。省略SDK公开流中的reasoning项；其余失败、非零工具退出和取消均保留。180秒是本程序的实际取消条件，不是模型会正确停止的保证。记录文件写入由此脚本完成，不能算作小说已保存或已采用。

固定前章是编者在前课中编辑并教学采用的r5，1059字符。三下、停顿、再一下的节奏在正文中，可通过读取查到。其余课堂条件的目标或选择不能从网络替作者决定。

重新运行会得到新的独立会话与目录。读者需逐字检查实际输出，不能因为报告有turnCompleted就认为任务已符合要求；遇到追问时，本轮完成仍可能表示正在等人的决定。
