# 切块与原文回查

本练习使用完整第三章、同一文字版PDF及已有页定位，比较返回材料能否支持同一个问题。小说是练习载体，稿件仍待人的内容决定。查看已有结果不读取PDF、不发模型请求。

## 独立恢复

解压到新的独立目录，在本文件所在lab目录运行。资料代码.bundle在上一级，包内运行材料需保留。

~~~powershell
git init
git fetch ../资料代码.bundle 'refs/tags/*:refs/tags/*'
git reset --mixed vcm-05-02-end
git rev-parse HEAD
python -X utf8 -m http.server 4345 --bind 127.0.0.1 --directory public
~~~

浏览器打开http://127.0.0.1:4345。Python标准库只提供静态文件；查看结束，在自己的终端按Ctrl+C。查看固定材料不需要安装Node依赖或填写凭据。

Git恢复只设置本练习的历史与HEAD，不覆盖包内观测文件。交付标签的确切提交和文件摘要见上一级固定版本与成员清单.json。没有.git的目录不能直接运行需要记录Git HEAD的观察命令。

## 已有观察

完整正文为1063个UTF-16码元、25段。固定80码元是让边界可见的课堂条件，不是token或生产最佳参数。

一次真实切分使用@langchain/textsplitters 1.0.2，比较无重叠、结构优先、40码元目标重叠。父范围条件复用无重叠全部小块，在首个字面命中后取回所在页正文。每个块保留全文、序号、正文位置与页关系；没有向量排序、BM25或自动重排。

四次真实问答顺序各运行一次，固定qwen-plus-2025-12-01、temperature 0、enable_thinking false、maxRetries 0。每次只带入各条件为“卡住”返回的完整材料、相同规则与问题，不携带前次回答。原请求、服务返回和SDK结果原样保留。

固定与重叠的首个返回块相同，实际回答也相同。结构返回70码元保留未知与理由，但缺前段观察。父页437码元补回观察，回答仍出现“共六次”“受控”及自称无推断的问题。HTTP 200与stop不是内容验收。

## 可选的重新观察

真实切分与问答使用Node.js 24.12.0、pnpm 11.20.0。按现有锁文件本地安装。

~~~powershell
pnpm install --frozen-lockfile
pnpm chunks:observe
~~~

切分命令不读取PDF、不调用模型，会写新的切分记录及public/chunks.json。若自行改过正文或切法，核对新的返回范围与旧问答完整输入；旧四次回答不是新条件的实测。问答记录保留sourceChunkRunId以便回查。

以下命令会发四次真实模型请求并产生费用，不是查看本练习的必要步骤。

~~~powershell
Copy-Item -LiteralPath .env.example -Destination .env
pnpm answers:observe
~~~

执行前在自己的.env填写合法凭据，确认服务、型号与提供方选项适用。不要公开.env。自然失败也保留，不为理想答案重复。每轮实际请求次数以记录为准；SDK没有配置自动重试。

## 练习页面

输入“卡住”并切换四种方法，回查第2页；输入“保留”，查看第3页安排；试一个无字面命中的词，观察输入仍在，未沿用旧回答。其他查询或另一个块没有对应问答时，页面明确没有该项实际问答。

原版、台面、笔记显示同一对象，换方向不消费模型。原版并列便于对照，台面集中工作区但来源更窄，笔记连续而来源靠后。功能、辨认与整体口吻分别判断，使用者决定采用方向。

## 位置与材料范围

正文范围是纯文字稿的UTF-16左闭右开位置，PDF页号是已核对物理页，二者不是图上的坐标。块ID随正文、切法和序号计算，不是永久业务身份。父范围按页ID查表，未运行ParentDocumentRetriever类；物理页不保证语义完整，跨页问题需扩大或调整范围。

inputs保留完整原文、已有解析原件、本轮页对应、问题和规则；public保留当前PDF、三页原图、正文与全部结果。已有解析JSON还包含前节其他输入的实际观察，本包不重新解析这些文件。旧生成与读取脚本也保留，完成本节无需执行，也无需OCR。

公开材料包含采用的代表视口及实际DOM/下载记录，不声称连续长页逐像素通读。早期异步视口、整页接口失败与未完成的浏览器下载留本机，公开范围说明逐项列明；实际全文另以DOM与下载原字节核对。教师回查提示未作为第五次模型请求执行。
