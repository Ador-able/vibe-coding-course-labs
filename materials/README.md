## 怎样检查自己的判断

逐份找到规则、首轮材料、草稿与追问的位置；用同一实际调用 ID 对上请求、工具结果与第二请求；区分服务历史和工作台采用记录；说明选中原文如何成为生成依据。材料可以支持这些判断，不证明任一接口生成更快、更好，也不替人决定文学采用。
