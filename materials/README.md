# 代码评审：先核实，再决定

这个练习接续已经修复的小说工作台，用现成编码助手评审实际差异，再依据代码、业务条件与历史结果处理意见。小说是完整文本与编辑数据的载体。本节没有生成小说、修改应用、重跑浏览器测试或选择界面风格。

## 先恢复到自己的独立目录

解压完整练习包到一个新的目录。需要 Node.js 24 与 Git；这一步不需要模型账户、应用依赖、HTTP 或数据库。保持包内路径，执行：

```powershell
node tools/恢复评审材料.mjs
```

程序从 `fixtures/应用固定存档.bundle` 创建包内独立的 `project/` Git 根，检出当前 `c3805c360551c10fedfd9b5473e569cfd7666dc0`，逐项核对 164 个跟踪文件的 Git 原字节与工作文件，再复制既有教师测试。项目已有时拒绝覆盖，失败保留目录与完整回执，不删除后自动重试。

正常结果是：应用 HEAD 为上述固定点，跟踪内容与索引零差异，唯一未跟踪文件为 `scripts/test-saving.mjs`；其 23625 字节 SHA256 为 `c2ce7ae8608d6f4437f6bb0c641754db35099d98a8f93e106b13b0e7fc318d92`。它是上一节的派生测试，不是本次评审新写的文件。恢复回执位于包根 `恢复完整回执.json`。

没有必要在这个只读评审练习安装、构建或启动应用。若要复做上一节红绿，沿该节已经说明的同一输入与测试入口；不能把重跑写成本节的新评审成果。

## 用成熟助手做一次有限评审

在现成编码助手中打开 `project/`，使用该宿主实际支持的只读权限。复制 `inputs/教师评审任务全文.md` 的完整输入；材料入口为 `../inputs/评审材料索引.json`。用户已有改动须先说明归属，本包的未跟踪测试则已经记录来源。

先报告，不让评审顺手安装、修改或写业务数据。原始报告保留，再单列人工判断。没有高置信度缺陷可以保留实现；不能为了完成练习要求某个问题数量。若确有重要但证据不足的条件，先交清最小验证范围，再决定是否执行。

本包也保存本课程的实际官方 `review/start` 输入：`inputs/review-start-完整参数模板.json`。它采用 `custom` 目标与 `inline` 交付；占位 threadId 必须来自自己的真实新会话，不能复制历史 ID。原生评审的模型、工具与内部任务由成熟宿主处理，一个客户端请求不代表一次底层推理。

`actual-definition/` 是作者当次观察器和非秘密配置的完整参考，不是可在任意设备直接执行的安装器。它含当次独立目录、固定官方入口、停用目录和审核范围；不要把其中的机器路径、旧全局摘要或 `approvedBy` 当成你当前环境已经适用。本包的公共恢复入口是上面的 `恢复评审材料.mjs`；自己的模型运行使用当前合法账户与宿主，不复制凭据或全局配置。

## 材料归属与判断范围

- `fixtures/` 是自主应用存档和完整固定树；旧行为为 `2c1f4e17c70377fc80e9f90d044e8e75ed3b5720`，既有修复为 `19f7f78bff6bf19a8ff5db47e0c95609524e3870`，当前采用点为 c380。应用改变仅为 `prototype/app.js`。
- `inputs/历史/` 是上一节的真实模型产物、定位失败、旧红新绿、完整请求、三章正文与数据库全文导出。十二个实际实例被不同时间的导出快照保留，不把快照份数当成独立数据库数量；本节没有新 GET、浏览器运行或数据库检查。
- `records/restore/`、`records/preflight/`、`records/review-task/` 分别保存作者当次恢复、唯一零模型空会话、唯一原生评审公共记录。它们不是读者恢复过程的回执。
- `sources/` 只有编者贡献、准确来源与实际阅读区间；整份原课、官方网页与源码留内部研究，不在公共包中。D034 的 .env 误报实际来自 AI Coder，第一份错误报告原件未保留，不能补造全文。

原记录中的 `D:/…` 及其他本机路径是当次位置或来源元信息，不是下载者的运行入口。定位代码和资料应使用包内同名路径及固定版本；不要访问记录中的其他用户目录。

采用当前修复的功能依据只覆盖实际等待和服务前 abort 条件。标签与状态字段存在不证明真人容易辨认；三个整页方向业务相同也不证明哪个更美。保留原版、台面和笔记方向，实际设计取舍仍需按相同业务和关键状态比较。文学表现由人的阅读判断，不以保存与测试通过替代。
