# 开始评读

这是一份材料阅读练习。既有实验原件与本节的教师标注、未运行卡、人工修正文分开保存。本包不启动模型、搜索服务、向量请求或业务库。

先打开教学材料/完整六类题集与判据.json。对每题写下问题、当前可用文件版本与位置，再打开所列完整原件。资料层看原页与提取结果，检索层看问题/筛选/候选完整文本，回答层逐句看原答/本轮上下文，再回完整原文核任务覆盖。

每题可用下面工作表，空白不代表通过：

| 项目 | 自己填写 |
| --- | --- |
| 问题与所需关系 | |
| 资料范围、版本、页或行 | |
| 实际已执行 / 教师未运行 | |
| 原件是否有读取缺口 | |
| 候选是否直接回答当前对象 | |
| 原答断言与支持原句 | |
| 没有覆盖或多说的内容 | |
| 应改哪一层、下一步补什么 | |
| 修改后同判据结果与旧正确项 | |

完整第三章是历史模型草稿，供回查，未被本章宣布文学采用。四个课堂文件和便签也是教学表达，不代表真人委托、付款或检查结果。报告前缀用于区分既有文件读取、切块问答、六条件检索和费用更新，实际runId和Git点以报告为准；四组记录不是同次运行。

E02使用本节标注，旧原排名不改变。基础前2项为AX-71委托、AX-17费用；限定后为AX-17费用、AX-17委托。判据只认直接给出检查对象与人的AX-17委托。程序只做算术：

```powershell
python -X utf8 教学材料/核对已有名次指标.py
```

它读取相邻的已有名次与本节人工标注.json；不安装包，不读取凭据，不发网络。实际本地算术与手算一致，输出另存教学材料/实际已有名次算术结果.json。这里不是新检索测试，也不是模型评分。召回分母尚未标全时记未评价；无答案题另评未知处理。

E04的人工修正文与同判据回查另存。它不是模型的新答案，四份原答没有改动。先自己逐句判断，再看三题完整问题提示与答案.md。完整未运行审核Prompt.txt可用于你之后的任务，但本包没有执行它，付费和结果另由使用者决定。

全资料输出和原文件已保留，方便阅读副本只省掉重复向量或选定阶段之外的字段，分别说明投影范围，完整原报告另存。原PDF需在阅读器打开，九原页图是既有读取结果，重开不等于重新解析。没有新的实践应用；前节已有的原版/台面/笔记方向和操作证据继续在对应可运行包，本章不声称新界面通过。

本包只含项目资料、实际公开记录和作者教学材料。第三方课程全文、官方全文快照、私有凭据、HTTP响应headers与内部主编核查不在其中。清单逐一列出当前成员、字节及SHA；方便阅读的投影不称完整原字节。
