本节在同一青岚宗世界中，用独立两章支线《雾里的药符》验收已有Agent。林青仍是炼气三层；铜片主线的章稿不导入此作品。

沿用已克隆的课程仓库。在本目录运行 `pnpm lab`，打开 `http://127.0.0.1:4367`，选择阶段并点“查看结果”。先读结论，再按需展开完整原答和过程；查看实录不调用模型。

## 亲自实践

复用第十章已有的Store、MCP、Skill和成熟Harness，不开发或复制一套Agent。完成第十章的一次依赖、构建及登录准备后，在本目录运行 `pnpm practice:prepare`。它新建独立SQLite，并将第十章工作台切到本次作品；原练习库和入口记录保留。

之后进入 `qinglan/chapter10/project`，沿用 `pnpm prototype` 查看和改稿，以及 `pnpm agent --prompt ../../chapter16/project/inputs/A-首章任务.txt --chapter 1 --stop-after-save` 发起一次首章任务。后两轮的完整输入、接续记录和人工操作以本节实际材料为准；源码切换不恢复或清空自己的数据库与会话。

A保存后停止、B只读检查、人的真实决定与改稿、C接续和两章导出分别保留记录。模型结束、业务保存、课堂采用和文件交付分别核对；模型调用按需执行，没有自动重跑。
