# 课堂实录来源

本章先冻结五份完整教师材料，再执行模型实验。完整输入与字节哈希见 `../materials/冻结清单.json`。真实记录按原字节保存，保留提供方返回、SDK公开投影、模型结束状态、向量和当前索引，不用摘要替代原件。

| 记录 | 来源与实际范围 |
| --- | --- |
| `reading.json` | PyMuPDF 1.27.2.2实际打开四份原件。三份读取到3个物理页；扫描版第2页文字为空但原图保留；损坏文件未取得页数。原页渲染288DPI，无OCR或模型调用。 |
| `chunks-final/report.json` | LangChain 1.0.2实际切分完整正文。四种方式分别为14、19、27、14个小块；字面定位与父页回查，零模型调用。 |
| `chunk-answers-01/report.json` | 四种上下文各请求一次文字服务，共4次真实HTTP。4096输出预算、temperature 0、maxRetries 0，没有主动关闭思考。 |
| `embeddings-01/report.json` | 实际向量服务处理19个结构小块、4份便签与3个查询，共26项、2560维，1次真实HTTP。文本直接传入，不加指令前缀，不在收到后主动归一化；服务内部处理未知。 |
| `retrieval-01/report.json` | Orama中文关键词检索、实际向量余弦和RRF共6个条件，保存完整排名与回查来源，零新增模型调用。 |
| `update-01/report.json` | A请求一次文字服务；新费用便签与独立追问共2项向量、1次真实HTTP；替换当前来源后B请求一次文字服务。共3次真实HTTP。旧引用保留；索引23→22→23，22个不变向量复用，保存后另读文件核对一致。 |

合计8次真实HTTP：6次文字、2次向量。这里统计实际进入fetch的尝试，不据调用次数推断服务计费。A、B均按实际返回保存，来源从FEE17-v1/TASK17-v1变为FEE17-v2/TASK17-v1。B只携带原问题和A实际完整回答作为必要历史，当前依据单独来自当前实际候选。

`source-version-initial.json`对应四次切块问答与26项向量；`source-version-update.json`对应A、新向量、来源更新和B；`source-version-display.json`标识页面版本。每份模型记录保存实际采集时的源码标识，不能用页面版本替换。

教师构造反例、无付款记录、同级安排冲突及药圃迁移题均保持未运行状态。`../project/public/records/evaluation.json`只对Q1实际RRF前2候选做本地算术，不进行模型判分，也不自动判定回答支持或采用。
