# 第四章写作实验

读者在自己已经使用的 AI 对话工具中完成实验。复制“材料”中的完整任务与指定样例，分别新建会话即可，不需要安装本目录或启动请求观察室。

材料是《青岚修仙录》的独立教学片段，尚未采用为小说正文。林青始终是青岚宗外门弟子、炼气三层；借阅炼气法门是为后续修行做准备，长远目标为筑基。

## 三种输入

- 不加样例：只使用“任务-S1.txt”。
- 冲突样例：在同一任务后追加“样例-冲突.txt”。
- 相容样例：在同一任务后追加“样例-相容.txt”。

保持工具与可选设置一致，保存完整输入与实际输出，再按“核对记录模板.md”逐份阅读。没有出现错误时，如实保留；输入冲突不代表输出一定出错。

“任务-S2.txt”和“任务-S3.txt”是后续复查材料。后续如何使用，应在实际读过首轮稿件、确定待改问题后固定；不要先拿其输出调方法，再称它们是未见样本。

## 作者验证入口

“运行实验.mjs”用已有 Codex 登录与固定 SDK 0.160.0 保存实际运行记录。默认依次运行无样例、冲突、相容、相容、冲突、无样例，共六次新会话。

复用已有安装时：

```powershell
node 运行实验.mjs --sdk-dir "已有实验目录/node_modules/@openai/codex-sdk"
```

本目录已安装依赖时也可使用：

```powershell
pnpm experiment
```

仅准备输入、不调用模型：

```powershell
node 运行实验.mjs --prepare
```

只观察一次时可加 `--condition none`、`--condition conflict` 或 `--condition consistent`。这会产生新的单次记录，不能替换一组比较中的失败结果。

每次运行单独保存到“运行记录”：固定条件和输入摘要、完整提示、公开事件、输出全文、耗时、用量与错误。每次调用最多等待 180 秒；失败保留已有输出和记录，其余预定条件继续运行，不自动重试。

生成完成不代表内容合格。按完整任务检查实际文字；额外工具事件需要核对。供应商内部重试、生效型号、实际账单和真人审阅工时未取得时保留未知。局部反馈与后续比较应根据真实新稿确定，不预设失败位置，也不用旧输出换名代替新实测。
