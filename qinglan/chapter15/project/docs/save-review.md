# 保存调查参考

先把本地修改、请求里的完整正文及其修订基线对上。当前POST在Store完成保存事务后返回本次草稿；页面随后GET读取当前作品，刷新与历史继续核对同一正文。

409时旧基线未被接受；保留本地稿后先读当前稿并对照。无HTTP响应时不能推断一定未保存。本节服务前abort例中，可结合完整服务器记录与库读回确认未写入。

资料版本、正文修订与前文依据分别核对。第2章变动后，第3章正文可以保持原字不变而basisCurrent=false。human是保存来源字段，不是身份验证，也不是文学采用。

程序通过后，还需看人能否辨认本地稿、已保存稿、远端对照和下一步操作。单一工作台的辨认与审美按实际页面判断，第二章是否正式采用由内容负责人决定；本次没有采用授权。
