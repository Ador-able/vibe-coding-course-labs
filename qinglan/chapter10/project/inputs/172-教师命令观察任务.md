# 当前三章的命令、等待与停止观察

这是编者安排的命令实验，不是模型自然提出的行动。使用前一节局部修订实际完成后的《青岚修仙录》三章与历史，在独立练习库中进行。先读取实际作品、章号、修订和状态；这里不预填尚未完成的第三章版本。全程不调用模型，不生成或修改小说，不采用、不发布。

复用现有 CLI、prototype 页面与成熟宿主的执行和停止入口。不要为了这节再造观察运行器或调度器。保存本次真实命令、工作目录、明确传入的运行标记、输出、原命令最终结果和必要的对象读回；不读取整个环境或凭据。本次命令不需要新增业务 Task，原有模型任务与正文历史保持。

先把同一小段条件报告程序分别放在普通管道与交互终端运行，读取它报告的 cwd、PID、stdin/stdout 是否为 TTY 和本次显式运行标记。保留真实返回，按实际通道说明输出；不预定最终返回一定为空，也不借终端控制字节补造业务文字。

复用现有约17行的 readline 教学门槛：程序先报告正在等待标准输入、尚未载入服务，读到一行 start 后才载入原 prototype 服务。本次在尚未输入 start 时停止这一确切过程。记录停止动作与原命令结束结果，核对应进程及端口；如果服务从未载入，就说明停止的是等待输入的过程，而不是已经可读的页面。

使用现有 CLI 把当前三章完整导出到本次明确文件。事先准备所需输出目录，保留完整返回和实际文件，核对标题、正文、顺序、修订与状态。没有必要的源码或依赖变化时，不重复已通过的构建；若真出现新的失败，保留实际错误与已完成部分，查清失败位置后只接续必要动作，不为复现旧案例而故意遗漏目录。

再用现有 prototype 启动本次阅读服务 A 与对照服务 B，使用两个空闲端口，分别保留对应运行身份。两者读取本次同一练习库，页面就绪后取得完整作品与章节内容，比较实际对象；页面能访问和启动命令仍在运行可以同时成立。只保留能说明本节状态的一两幅清楚局部图，不再比较三套页面布局。

在 A 已可读、导出文件已存在时，停止本次 A 的确切过程。将停止请求的返回与原启动动作的最终结果分开记录；随后核对应进程、监听、A 的访问结果、导出文件是否仍在及 B 是否仍可读。停止只针对本次身份，不按程序名批量结束进程，不影响其他任务。若停止发生于自动超时，应如实写超时，不记作人工停止。

最后停止自己启动的 B，核对它的原动作结果与端口。重新读取完整导出和练习库，确认小说、历史与已有模型任务是否保持。截图里的拒绝连接若由浏览器显示，要明确属于浏览器反馈，不能冒充小说工作台已经提供的状态页面。

交付时分别说明：有限命令是否结束、持续服务是否可读或已经停止、完整文件是否留存，以及小说还有哪些采用判断没有发生。只依据本次真实返回填写进程标识、端口、用时与退出码；不复用旧实验的数字、失败或取消结论。
