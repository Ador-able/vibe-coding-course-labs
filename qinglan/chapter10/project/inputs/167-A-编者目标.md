# 为第三章建立待规划对象

编者先建立第三章这个待讨论对象，让本轮任务绑定到真实章号；这一步不选择剧情路线，不生成正文，也不采用前两章。其余要求、设定、前两章大纲与全部正文历史保持。

作品用途改为：用连续三章待审草稿观察方案比较、人的选择与实际改稿怎样影响后续任务，供人工阅读判断。

在大纲末尾增加：

```json
{
  "number": 3,
  "titleHint": "第三章待定",
  "goal": "本章目标待规划。基于第二章实际结尾提出两个可比较的推进方向，保留人物身份、修为、借阅目的、既有行动条件与尚未查明的异常原因。具体路线、章名及新增情节待人选择，本阶段不写第三章正文。"
}
```

先通过现有资料更新入口保存，并完整读回核对。第三章仍无正文；资料多了章号不表示章稿已经完成。两个方案自然产生并经人阅读选择后，再将这条待定目标替换为实际要写的目标。
