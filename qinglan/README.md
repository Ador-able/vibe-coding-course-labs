# 青岚修仙录实验

课程实验共用青岚宗、外门弟子林青、炼气三层与筑基愿望。各节使用的独立作品与教学片段按本章材料核对，不把不同分支混成一部定稿。

## 获取与继续

沿用首次准备的 Git、Node.js 和 pnpm，只克隆一次：

```powershell
git clone https://github.com/Ador-able/vibe-coding-course-labs.git
cd vibe-coding-course-labs
pnpm install --frozen-lockfile
pnpm build
```

后续进入本节对应目录，沿用已完成的准备。各章 README 提供实际入口；只读完整材料与实录不需要调用模型。

| 章节 | 入口目录 | 使用方式 |
| --- | --- | --- |
| 第三章：渐进式读取 | chapter03/project | 先读材料包与真实三种读法记录；新实验使用当前 Codex 登录。 |
| 第四章：任务、样例与反馈 | chapter04/project | 复制完整任务与指定材料到现成 AI 工具，按核对表阅读结果。 |
| 第五章：工具与 Agent | chapter05/project | 一次安装与构建后，按 README 准备独立作品库，沿同一项目继续。 |
| 第七章：插件与方法 | chapter07/project | 共用完整小说资料、方法与插件，按本节选择入口。 |
| 第八章：原型与跨会话 | chapter08/project | 比较同一资料的三种界面，再按实际状态继续任务。 |
| 第九章：子代理与汇总 | chapter09/project | 阅读完整公开任务、工具结果与最终回答；新任务沿用当前宿主。 |
| 第十章：连续 Agent | chapter10/project | 恢复本节起点，在同一工作台核对、修改、接续和导出。 |
| 第十二章：资料、检索与回答 | chapter12/project | 在同一工作台依次回查原页、切块、两路检索、资料更新和评估。 |
| 第十三章：小说材料整理 | [chapter13/project](chapter13/project/README.md) | 一个工作台回查长文、反馈分类、日志抽取、逐项状态与模板核对；默认只读课堂实录。 |

表中目录位于本仓库 qinglan/ 下。仓库根的一次安装和构建覆盖表中所有项目，并沿用各项目锁定的版本。后续直接进入相应 project 使用本节入口。修改源码后重新构建即可，不用重做已有模型任务。

[请求观察室](https://github.com/Ador-able/vibe-coding-ai-request-lab)共用网页负责第三、六、十一章的请求与输出实验；后续沿用同一克隆目录和页面模型设置。[模型机制观察室](https://github.com/Ador-able/vibe-coding-model-mechanics-lab)按原课程入口使用。

## 实际结果与个人数据

材料、教学输入和课堂实录随源码提供。实际模型输出、教师材料、受控输入与公开事件按各章来源说明区分；历史绝对路径只标识采集环境，运行时使用本次返回。保留失败、取消和未执行状态，生成结束、业务保存与人的采用分别核对。

各项目自己的数据库、登录和新运行记录保存在被 Git 忽略的目录中。继续之前先读取已有状态；恢复起点按本节规则建立独立库，不覆盖作品。账户登录沿用宿主配置，仓库不提供凭证。
