# 第七章教学材料

本包用于《青岚修仙录》的插件、MCP、Skill 和 Hook 练习。林青是青岚宗外门弟子，炼气三层，长远目标是筑基。本章围绕藏书阁中的借阅与书页异动展开，每个实验独立保存自己的内容。

三章阅读材料已备好，不需要先调用模型生成。第一章《阁前问路》沿用前章展示的正文；第二章《窗边的纸》和第三章《合窗以后》由编者为本章练习编写。它们接续第一章的人工改稿，与前章其他候选稿分开使用。

- `作品-r1.json`、`作品-r2.json`：作品要求、已知事实和章节目标。r2 增加了书页与四折纸同时运动的观察。
- `第一章-r1.md`、`第一章-r2.md`：原稿和人工改稿。r2 只在末尾增加一段观察，其余正文相同。
- `第二章-教学候选.md`、`第三章-教学候选.md`：后续阅读材料，供检查情节衔接与判断依据。
- `局部练习.json`：入阁令归属、待补进门动作、旧反馈等独立短例，供练习方法读取、保存后检查与意见复核。
- `插件起草-作品.json`、`插件起草-任务.txt`：从空章节开始起草的独立练习，未预置三章正文。

作品标识统一为 `qinglan`。各实验使用独立数据库；同名作品在不同数据库中可以有不同内容。按对应课程入口准备材料后，应从工具实际返回的正文、修订和状态确认保存结果。文件存在本身不表示它已经进入业务库。

三章阅读练习会把第一章设为“教学采用”，用来观察采用后的状态和读取结果；第二、三章保留为草稿。“教学采用”不评价小说的文学质量。

第一章新增的事实是：两次右页翘起时，四折纸都轻抖。这只说明两种现象同时被观察到，尚不能确定因果。第二章开窗时纸动、书不动；第三章合窗后书页起、未见纸动，最后纸动、书页不动。阅读时留意：这些现象能支持哪些判断，哪些问题仍未解释。

对象保存、MCP 连接、资源和提示等协议练习不调用模型。插件读取、起草与修改练习会使用当前 Agent 的模型服务；按课程步骤选择需要体验的部分即可。
